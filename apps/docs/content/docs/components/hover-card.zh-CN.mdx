## 安装 [#installation]

```bash
bunx --bun shadcn@latest add @sui/hover-card
```

通过 shadcn CLI 安装组件源码。按照[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

## 使用方法 [#usage]

```tsx showLineNumbers
import {
  HoverCard,
  HoverCardContent,
  HoverCardTrigger,
} from "@workspace/ui/components/hover-card"
```

```tsx showLineNumbers
<HoverCard>
  <HoverCardTrigger>Hover</HoverCardTrigger>
  <HoverCardContent>
    The React Framework – created and maintained by @vercel.
  </HoverCardContent>
</HoverCard>
```

## 组合结构 [#composition]

使用以下组合来构建 `HoverCard`：

```text
HoverCard
├── HoverCardTrigger
└── HoverCardContent
```

## 触发延迟 [#trigger-delays]

使用触发器上的`delay`和`closeDelay`来控制卡何时打开和
关闭。

```tsx showLineNumbers
<HoverCard>
  <HoverCardTrigger delay={100} closeDelay={200}>
    Hover
  </HoverCardTrigger>
  <HoverCardContent>Content</HoverCardContent>
</HoverCard>
```

## 定位 [#positioning]

使用 `HoverCardContent` 上的 `side` 和 `align` 属性来控制放置。

```tsx showLineNumbers
<HoverCard>
  <HoverCardTrigger>Hover</HoverCardTrigger>
  <HoverCardContent side="top" align="start">
    Content
  </HoverCardContent>
</HoverCard>
```
