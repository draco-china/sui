## 安装 [#installation]

```bash
bunx --bun shadcn@latest add @sui/progress
```

通过 shadcn CLI 安装组件源码。按照[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

## 使用方法 [#usage]

```tsx showLineNumbers
import { Progress } from "@workspace/ui/components/progress"
```

```tsx showLineNumbers
<Progress value={33} />
```

## 组合结构 [#composition]

### 带标签与数值 [#with-label-and-value]

使用`ProgressLabel`和`ProgressValue`添加标签和值显示。

```tsx showLineNumbers
import {
  Progress,
  ProgressLabel,
  ProgressValue,
} from "@workspace/ui/components/progress"

;<Progress value={56} className="w-full max-w-sm">
  <ProgressLabel>Upload progress</ProgressLabel>
  <ProgressValue />
</Progress>
```

```text
Progress
├── ProgressLabel
├── ProgressValue
└── ProgressTrack
    └── ProgressIndicator
```
