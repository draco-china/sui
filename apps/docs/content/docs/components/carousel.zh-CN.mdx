## 关于 [#about]

轮播组件是使用 [Embla Carousel](https://www.embla-carousel.com/) 库构建的。

## 安装 [#installation]

```bash
bunx --bun shadcn@latest add @sui/carousel
```

通过 shadcn CLI 安装组件源码。按照[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

## 使用方法 [#usage]

```tsx showLineNumbers
import {
  Carousel,
  CarouselContent,
  CarouselItem,
  CarouselNext,
  CarouselPrevious,
} from "@workspace/ui/components/carousel"
```

```tsx showLineNumbers
<Carousel>
  <CarouselContent>
    <CarouselItem>...</CarouselItem>
    <CarouselItem>...</CarouselItem>
    <CarouselItem>...</CarouselItem>
  </CarouselContent>
  <CarouselPrevious />
  <CarouselNext />
</Carousel>
```

## Options [#options]

您可以使用 `opts` 属性将选项传递给轮播。有关详细信息，请参阅 [Embla 轮播文档](https://www.embla-carousel.com/api/options/)。

```tsx showLineNumbers {2-5}
<Carousel
  opts={{
    align: "start",
    loop: true,
  }}
>
  <CarouselContent>
    <CarouselItem>...</CarouselItem>
    <CarouselItem>...</CarouselItem>
    <CarouselItem>...</CarouselItem>
  </CarouselContent>
</Carousel>
```

## API [#api]

使用状态和 `setApi` 属性来获取轮播 API 的实例。

<ComponentPreview name="carousel-api" previewClassName="sm:h-[32rem]" />

```tsx showLineNumbers {1,4,22}
import { type CarouselApi } from "@workspace/ui/components/carousel"

export function Example() {
  const [api, setApi] = React.useState<CarouselApi>()
  const [current, setCurrent] = React.useState(0)
  const [count, setCount] = React.useState(0)

  React.useEffect(() => {
    if (!api) {
      return
    }

    setCount(api.scrollSnapList().length)
    setCurrent(api.selectedScrollSnap() + 1)

    api.on("select", () => {
      setCurrent(api.selectedScrollSnap() + 1)
    })
  }, [api])

  return (
    <Carousel setApi={setApi}>
      <CarouselContent>
        <CarouselItem>...</CarouselItem>
        <CarouselItem>...</CarouselItem>
        <CarouselItem>...</CarouselItem>
      </CarouselContent>
    </Carousel>
  )
}
```

## Events [#events]

您可以使用 `setApi` 的 api 实例监听事件。

```tsx showLineNumbers {1,4-14,16}
import { type CarouselApi } from "@workspace/ui/components/carousel"

export function Example() {
  const [api, setApi] = React.useState<CarouselApi>()

  React.useEffect(() => {
    if (!api) {
      return
    }

    api.on("select", () => {
      // Do something on select.
    })
  }, [api])

  return (
    <Carousel setApi={setApi}>
      <CarouselContent>
        <CarouselItem>...</CarouselItem>
        <CarouselItem>...</CarouselItem>
        <CarouselItem>...</CarouselItem>
      </CarouselContent>
    </Carousel>
  )
}
```

有关使用事件的更多信息，请参阅 [Embla Carousel 文档](https://www.embla-carousel.com/api/events/)。

## 从右到左 [#rtl]

关于 shadcn/ui 的 RTL 支持，参阅 [RTL 配置指南](https://ui.shadcn.com/docs/rtl)。

<ComponentPreview name="carousel-rtl" previewClassName="h-80 sm:h-[32rem]" direction="rtl" />

将轮播本地化为 RTL 语言时，需要在 `opts` 中设置 `direction`，使其与文字方向一致，确保轮播朝正确的方向滚动。

```tsx showLineNumbers {2-5}
<Carousel
  dir={dir}
  opts={{
    direction: dir,
  }}
>
  <CarouselContent>
    <CarouselItem>...</CarouselItem>
    <CarouselItem>...</CarouselItem>
    <CarouselItem>...</CarouselItem>
  </CarouselContent>
  <CarouselPrevious className="rtl:rotate-180" />
  <CarouselNext className="rtl:rotate-180" />
</Carousel>
```

`direction` 接受 `"ltr"` 或 `"rtl"`，应与 `dir` 的值一致。还可为导航按钮添加 `rtl:rotate-180`，确保图标指向正确方向。
