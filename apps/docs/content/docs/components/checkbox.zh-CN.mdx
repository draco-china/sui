## 安装 [#installation]

```bash
bunx --bun shadcn@latest add @sui/checkbox
```

通过 shadcn CLI 安装组件源码。按照[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

## 使用方法 [#usage]

```tsx
import { Checkbox } from "@workspace/ui/components/checkbox"
```

```tsx
<Checkbox />
```

## 选中状态 [#checked-state]

对于不受控制的复选框使用 `defaultChecked`，或使用 `checked` 和
`onCheckedChange`控制状态。

```tsx showLineNumbers
import * as React from "react"

export function Example() {
  const [checked, setChecked] = React.useState(false)

  return <Checkbox checked={checked} onCheckedChange={setChecked} />
}
```

## 无效状态 [#invalid-state]

将复选框上的 `aria-invalid` 和字段包装器上的 `data-invalid` 设置为
显示无效样式。
