## 安装 [#installation]

```bash
bunx --bun shadcn@latest add @sui/skeleton
```

通过 shadcn CLI 安装组件源码。按照[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

## 使用方法 [#usage]

```tsx
import { Skeleton } from "@workspace/ui/components/skeleton"
```

```tsx
<Skeleton className="h-[20px] w-[100px] rounded-full" />
```
