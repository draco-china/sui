TabBar 以 iOS 的方式呈现应用的主要目的地。它只管理选中状态，路由与内容由应用自行处理。

<ComponentPreview name="tab-bar-demo" />

## 安装 [#installation]

```npm
npx shadcn@latest add @sui/tab-bar
```

可通过 shadcn CLI 安装，也可直接使用共享的 `@workspace/ui` 包。请参阅[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

## 使用 [#usage]

```tsx
import { TabBar } from "@workspace/ui/components/tab-bar";
import { HomeIcon, SettingsIcon } from "lucide-react";
import { useState } from "react";

export function ApplicationNavigation() {
  const [value, setValue] = useState("home");
  return (
    <TabBar
      aria-label="应用导航"
      value={value}
      onValueChange={setValue}
      items={[
        { value: "home", label: "首页", icon: <HomeIcon /> },
        { value: "settings", label: "设置", icon: <SettingsIcon /> },
      ]}
      search={{ onSubmit: (query) => console.log(query) }}
    />
  );
}
```

`value` 表示当前目的地，`onValueChange` 通知应用切换到另一目的地，应用可据此更新路由或展示自己的视图。各项的值必须唯一。TabBar 渲染由按钮组成的导航 landmark，并以 `aria-current` 标识当前项；它不渲染内容面板，页面内切换面板请使用 [Tabs](/zh-CN/docs/components/tabs)。

## 应用中使用 [#app]

手机尺寸的界面：标签栏切换页面内容，搜索框随输入实时筛选所有条目。这里搜索为受控模式，展开期间页面显示搜索结果。

## 材质 [#material]

默认标签栏使用主题的 muted 表面。传入 `glass`（可带设置 `glass={{ … }}`）或 `frosted` 后，标签栏及其搜索按钮使用 [Glass](/zh-CN/docs/components/glass) 材质。两者都保持与 iOS 一致的中性选中胶囊，图标和文字使用经过对比度调整的主题前景色。外层容器请保持普通表面，避免玻璃嵌套。

<ComponentPreview name="tab-bar-material" />

## 搜索 [#search]

`search` 会在尾侧增加一个独立的圆形按钮，与 iOS 26 及更新版本一致。点按后标签栏隐藏，搜索框从按钮向前侧展开，宽度与原标签栏加按钮相同。点按关闭按钮或按 Escape 时，搜索框先收回按钮，标签栏再淡入；按 Enter 调用 `onSubmit`。

<ComponentPreview name="tab-bar-search" />

搜索框默认非受控（`defaultOpen`、`defaultValue`）；传入 `open`/`onOpenChange` 或 `value`/`onValueChange` 可受控。`placeholder`、`label`、`closeLabel` 和 `icon` 用于自定义。从搜索框关闭后，焦点回到搜索按钮；视口变化时，展开的搜索框保持与标签栏相同的宽度。

### 仅按钮 [#search-button]

设置 `mode: "button"` 后按钮不会展开，由 `onActivate` 自行处理，例如打开搜索面板、跳转路由，或像示例一样作为其他尾侧操作。

## 键盘 [#keyboard]

左右方向键在可用目的地间移动，Home 和 End 聚焦第一个与最后一个。移动焦点不会改变目的地，Enter 或空格激活聚焦项。只有当前目的地参与 Tab 焦点顺序。目的地超出可用空间时标签栏可滚动。

## 长按与滑动 [#long-press]

按住某项 250ms 或拖动超过 6px，选中背景会浮起为镜片，图标与文字轻微放大。滑动可把镜片移到其他项上，松手即选中镜片下的项。拖过两端时镜片带阻尼继续跟随并保持末端项。在远离标签栏处松手、取消指针或窗口失焦时恢复原选择。玻璃模式下镜片透明，只保留边缘高光与悬浮阴影，不模糊也不折射，底层玻璃保持静止。

## 动画 [#motion]

GSAP 依据按钮实际尺寸移动选中胶囊与镜片。搜索框一开始就取最终宽度，再以圆角裁剪逐步显露，玻璃材质因此只测量一次，而不必跟随尺寸变化；收起时裁剪反向播放，随后标签栏淡入。开启减少动态效果时这些动画全部关闭。

## API 参考 [#api-reference]

| 属性 | 类型 | 默认值 / 行为 |
| --- | --- | --- |
| `items` | `readonly TabBarItem[]` | 目的地：`value`、`label`，可选 `icon` 与 `disabled`。 |
| `value` | `string` | 受控的当前目的地。 |
| `onValueChange` | `(value: string) => void` | 选中可用目的地时调用。 |
| `onItemActivate` | `(value: string) => void` | 每次激活时调用，包括当前项。 |
| `search` | `TabBarSearch` | 可选的尾侧搜索按钮，见下表。 |
| `glass`、`frosted` | `boolean \| GlassConfig`、`boolean` | `false`；标签栏与搜索按钮的材质。 |
| `size` | `"sm" \| "default" \| "lg"` | `"default"`。 |
| `feedback` | `FeedbackOption` | 跟随 `FeedbackProvider`；选中与长按时触发触感反馈。 |
| 其他属性 | 原生 nav 属性 | 包括 `aria-label`、`dir`、`className`、`style` 与 `ref`。 |

### TabBarSearch [#tab-bar-search]

| 字段 | 类型 | 默认值 / 行为 |
| --- | --- | --- |
| `mode` | `"expand" \| "button"` | `"expand"`。 |
| `label` | `string` | `"Search"`；无障碍名称与占位符后备。 |
| `icon` | `ReactNode` | 搜索图标。 |
| `onActivate` | `() => void` | 点按按钮或展开搜索框时调用。 |
| `open`、`defaultOpen`、`onOpenChange` | `boolean`、`boolean`、`(open: boolean) => void` | 是否显示搜索框。 |
| `value`、`defaultValue`、`onValueChange` | `string`、`string`、`(value: string) => void` | 搜索内容。 |
| `onSubmit` | `(value: string) => void` | 按 Enter 时调用。 |
| `placeholder` | `string` | 默认使用 `label`。 |
| `closeLabel` | `string` | 默认 `"Close search"`，关闭按钮的无障碍名称。 |
| `render` | `({ open, close }) => ReactNode` | 替换搜索框。 |
