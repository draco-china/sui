## Usage [#usage]

```tsx
import { GlassSurface } from "@workspace/ui/components/glass";

<GlassSurface className="rounded-2xl bg-background p-6">
  Glass surface
</GlassSurface>
```

`glass` is a boolean switch on every glass-capable component. `glassConfig` chooses the `material`, the `edge` light and three `options`: `strength`, `tint` and `tintOpacity`. Blur, saturation and the edge highlight strength are built in. Configuration never becomes an HTML attribute, and an explicit `glass={false}` always turns the effect off.

```tsx
import { Button } from "@workspace/ui/components/button";
import { GlassSurface } from "@workspace/ui/components/glass";

<GlassSurface glassConfig={{ material: "clear", edge: "vertical" }} />
<Button glass glassConfig={{ material: "regular" }}>Action</Button>
```

Pass `render` to keep native semantics, for example `<GlassSurface render={<nav />} />`. Each enabled surface is an independent request; observers, listeners and the SVG renderer are shared internally, so no Provider is required. Roots such as Dialog, Popover or Tabs pass their setting to their controls and popups without becoming glass themselves.

## Rendering [#rendering]

Glass renders native SVG refraction: a geometric displacement map bends the live backdrop along the edges with `feDisplacementMap`, then blurs and saturates it. Nothing is captured, so video, scrolling and animation stay live at the display's frame rate.

The CSS material is the fallback. It applies before a surface is measured, in browsers that cannot paint SVG backdrops (Safari), under `prefers-reduced-transparency` or forced colors, and if the renderer fails. Fully opaque paint covers the backdrop, so such surfaces keep CSS with the shared edge highlight. Reduced transparency and forced colors show an opaque base with native focus styles.

<ComponentPreview name="glass-dynamic" />

`refreshGlass(target?)` re-measures materials and edges of mounted surfaces inside an element or ref, or all of them when the target is omitted. Call it after changing paint the runtime cannot observe.

## Materials [#materials]

Two materials follow [Apple's Clear and Regular variants](https://developer.apple.com/design/human-interface-guidelines/materials); the values are Web approximations, not Apple specifications.

| Material | Tint | SVG blur | CSS blur | Use |
| --- | --- | --- | --- | --- |
| `"clear"` | `12%` | `4px` | `6px` | See-through glass over media; the backdrop stays recognizable. |
| `"regular"` (default) | `30%` | `14px` | `16px` | Frosted glass that keeps text legible over busy content. |

Both use refraction strength `22`, saturation `1.3` and the same edge light. `options.tintOpacity` overrides a material's tint. The tint comes from the component's own background, so primary and destructive paint keep their color. From bottom to top, a surface composes the refracted backdrop, the tint, component paint, the edge highlight and content.

## Edge light [#edge]

`glassConfig.edge` chooses how light falls on the rim:

- `"diagonal"` (default): a thin rim lit from the top-left and bottom-right corners, fading along the sides.
- `"vertical"`: a lit bevel with reflections along the top and bottom edges.

<ComponentPreview name="glass-edges" />

The highlight strength is built in and follows pixel density continuously (`0.15 × device pixel ratio`, from `0.15` to `0.3`), so 1x screens draw a fainter edge and phones a finer one.

## Popups [#popups]

With glass on, menus, popovers, selects, tooltips, hover cards, dialogs, sheets, drawers and toasts use the legible Regular material with vertical edge light, whatever their surroundings use, as on Apple platforms. Their own `glassConfig` still chooses otherwise. Floating layers share one soft, diffuse shadow.

## Controls and content [#composition]

Glass belongs to navigation, controls and floating layers; content stays ordinary.

- Controls inside a glass surface share its material instead of becoming separate glass, unless they explicitly opt in.
- A `ButtonGroup` is one capsule whose buttons share its material; a group of groups keeps one capsule per inner group. `Pagination` controls form the same capsule.
- Form fields (`Input`, `Textarea`, `InputGroup`, `Select` and `Combobox` triggers, `TagInput`, `SensitiveInput`, `ClipboardText`) are glass on their own in a glass scope, like iOS search fields, and brighten slightly while focused. Inside a glass surface such as a dialog or panel, they stay ordinary fields with their focus rings.
- Switch and Slider thumbs become a glass lens only while dragged. Pressed buttons bloom slightly, and glass buttons also brighten.
- A glass `Carousel` floats its previous and next buttons as glass while the slides stay content.
- Card, QR code, Accordion, Calendar, editors and viewers are content: their own controls stay ordinary inside glass, while menus and popovers they open still use glass. `Card` and `QRCode` accept an explicit `glass` prop, for example for a widget over media.
- Wrap your own content regions in `GlassContent` to keep their controls ordinary inside a glass surface.

<ComponentPreview name="glass-controls" />

```tsx
import { Card } from "@workspace/ui/components/card";
import { GlassContent, GlassSurface } from "@workspace/ui/components/glass";

<GlassSurface>
  <GlassContent>{/* ordinary form fields */}</GlassContent>
</GlassSurface>
<Card glass>{/* a glass widget */}</Card>
```

<ComponentPreview name="glass-composition" />

Glass focus adds no ring; ordinary components keep their theme and focus styling. Glass shows the backdrop through, most of all with Clear, so text and icons on both materials carry a soft glow in the material's own tint, like a little extra frost right behind them, and secondary text moves toward the foreground. The glow only shows where the backdrop fights the text, so they stay legible over bright, busy content in light and dark mode. Ordinary buttons and fields keep crisp labels, and reduced transparency turns both off along with the glass.

## API reference [#api-reference]

| Prop | Type | Default / behavior |
| --- | --- | --- |
| Config `material` | `"clear" \| "regular"` | `"regular"`; popups default to `"regular"`. |
| Config `edge` | `"diagonal" \| "vertical"` | `"diagonal"`; popups default to `"vertical"`. |
| Config `options` | `GlassOptions` | Local material settings. |
| Options `strength` | `number` | `22` |
| Options `tint` | `string` | Component background. |
| Options `tintOpacity` | `number` | Material default: `0.12` / `0.3`. |
| `refreshGlass(target?)` | `(target?: GlassTarget) => void` | Re-measure surfaces inside the target, or all when omitted. |
| Component `glass` | `boolean` | Enables or disables glass; `GlassSurface` defaults to `true`. |
| Component `glassConfig` | `GlassConfig` | Local `material`, `edge` and `options`. |
| `GlassSurface` | `useRender` props | Native div props, plus `render` to change the element. |
| `GlassContent` | `useRender` props | An ordinary content region inside glass. |
