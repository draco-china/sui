## 安装 [#installation]

```bash
bunx --bun shadcn@latest add @sui/label
```

通过 shadcn CLI 安装组件源码。按照[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

## 使用方法 [#usage]

```tsx
import { Label } from "@workspace/ui/components/label"
```

```tsx
<Label htmlFor="email">Your email address</Label>
```

## 字段中的标签 [#label-in-field]

对于表单字段，请使用 [Field](/zh-CN/docs/components/field) 组件，该组件
包括内置 `FieldLabel`、`FieldDescription` 和 `FieldError` 组件。

```tsx
<Field>
  <FieldLabel htmlFor="email">Your email address</FieldLabel>
  <Input id="email" />
</Field>
```
