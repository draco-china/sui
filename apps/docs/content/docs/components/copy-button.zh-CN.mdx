## 安装

```bash
bunx --bun shadcn@latest add @sui/copy-button
```

通过 shadcn CLI 安装组件源码，或使用共享的 `@workspace/ui` 包。按照[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

```tsx
import { CopyButton } from "@workspace/ui/components/copy-button";
```

## 使用

```tsx
<CopyButton value={command} />
```

剪贴板写入成功后图标变为对勾，失败变为叉号，提示文字和礼貌型实时区域同步播报。写入进行中按钮禁用。它是一个 [Tooltip Button](/zh-CN/docs/components/tooltip-button)，`variant`、`size`、`disabled`、`className` 均可透传，默认为小号 ghost 图标按钮。[Code Viewer](/zh-CN/docs/viewers/code-viewer)、[Diff Viewer](/zh-CN/docs/viewers/diff-viewer) 以及 [Code Editor](/zh-CN/docs/components/code-editor) 的 `copy()` 插件都使用它。

## 文案

`labels` 可覆盖 `copy`、`copied`、`copyFailed`，传入 `copyButtonLabelsZhCN` 使用中文。

## API 参考

| 属性 | 类型 | 默认值 / 行为 |
| --- | --- | --- |
| `value` | `string` | 必填，要复制的文本。 |
| `labels` | `Partial<CopyButtonLabels>` | 英文文案。 |
| `variant`、`size` | Button 属性 | `"ghost"`、`"icon-sm"`。 |

模块导出 `CopyButtonProps`、`CopyButtonLabels`、`copyButtonLabels` 和 `copyButtonLabelsZhCN`。
