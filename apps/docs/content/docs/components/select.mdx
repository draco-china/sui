## Installation

```bash
bunx --bun shadcn@latest add @sui/select
```

Install with the shadcn CLI or use the shared `@workspace/ui` package. Follow the [installation guide](/docs/installation) to configure the registry, load styles, and choose import aliases.

## Usage

```tsx showLineNumbers
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectList,
  SelectTrigger,
  SelectValue,
} from "@workspace/ui/components/select"
```

```tsx showLineNumbers
const items = [
  { label: "Light", value: "light" },
  { label: "Dark", value: "dark" },
  { label: "System", value: "system" },
]

<Select items={items}>
  <SelectTrigger className="w-[180px]">
    <SelectValue placeholder="Theme" />
  </SelectTrigger>
  <SelectContent>
    <SelectList>
      {items.map((item) => (
        <SelectItem key={item.value} value={item.value}>
          {item.label}
        </SelectItem>
      ))}
    </SelectList>
  </SelectContent>
</Select>
```

## Composition

`Select` takes its shape from the parts you put in it. Every shape shares `SelectContent`, `SelectList` and `SelectItem`.

```text
Select
├── SelectTrigger            ← plain dropdown
│   └── SelectValue
├── SelectInput              ← text input as the trigger
├── SelectChips              ← multiple values as chips
│   ├── SelectChip
│   └── SelectChipsInput
└── SelectContent
    ├── SelectSearch         ← search box inside the popup
    ├── SelectEmpty
    └── SelectList
        ├── SelectGroup
        │   ├── SelectLabel
        │   └── SelectItem
        ├── SelectSeparator
        └── SelectItem
```

## Searchable

The popup has no search box until you add one: put `SelectSearch` inside `SelectContent` to filter the list. Static `SelectItem` children are filtered too when `Select` has `items`. Without it the arrow keys and Enter still work.

## Invalid

Add the `data-invalid` attribute to the `Field` component and the `aria-invalid` attribute to the `SelectTrigger` component to show an error state.

```tsx showLineNumbers /data-invalid/ /aria-invalid/
<Field data-invalid>
  <FieldLabel>Fruit</FieldLabel>
  <SelectTrigger aria-invalid>
    <SelectValue />
  </SelectTrigger>
</Field>
```
