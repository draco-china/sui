## 安装 [#installation]

```bash
bunx --bun shadcn@latest add @sui/diff-viewer
```

通过 shadcn CLI 安装组件源码。按照[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

## 使用 [#usage]

```tsx
import { DiffViewer } from "@workspace/ui/components/diff-viewer";

<DiffViewer
  oldCode={'const enabled = false;'}
  newCode={'const enabled = true;'}
  filename="settings.ts"
  lang="typescript"
/>;
```

## 并排与合并视图 [#views]

默认在左右区域并排显示修改前后的代码，可通过视图控件切换为合并列表。新增和删除行具有不同颜色及对应行号。`oldTitle`、`newTitle` 和 `filename` 可定制标题。差异按行比较，不展示逐字符的变更。

新旧源码独立高亮，使跨行字符串和注释保留各版本的词法上下文。统一视图的未变行使用新源码上下文，双栏各自沿用对应版本的上下文。

双栏标题保持单行，长标题省略显示，悬停可查看完整文本，避免一侧换行导致代码行错位。页首示例包含长短标题对照，可在窄屏检查对齐。

通过 `maxHeight` 限制滚动区高度。滚动区可以通过 Tab 聚焦，显示主题色焦点环，并支持键盘滚动。

## 流式修改 [#streaming]

逐步生成 `newCode` 时使用 `status="streaming"`，结束后改为 `"complete"`。接近底部时自动跟随内容，向上滚动后暂停跟随，回到底部恢复。示例在本地逐行追加 JSON 修改内容，并通过 `copyable={false}` 关闭复制。

## 复制与本地化 [#copy]

复制操作写入 `newCode`，不是补丁或旧版本。语法高亮异步加载，失败时回退为可读的纯文本行。未传入 `theme` 时使用周围主题。通过 `labels` 翻译版本名称、视图控件、状态和复制反馈。

## API 参考 [#api-reference]

| 属性 | 类型 | 默认值／说明 |
| --- | --- | --- |
| `oldCode`、`newCode` | `string` | 必填的两版源码 |
| `oldTitle`、`newTitle` | `string` | 可选版本标题 |
| `filename` | `ReactNode` | 可选文件标题 |
| `lang` | `string` | `"typescript"` |
| `theme` | `"light" \| "dark"` | 跟随周围主题 |
| `status` | `"streaming" \| "complete"` | `"complete"` |
| `maxHeight` | `number` | `280` 像素 |
| `copyable` | `boolean` | `true`；复制修改后的代码 |
| `labels` | `Partial<DiffViewerLabels>` | 英文文案 |
| `glass` | `boolean` | `false` |

模块导出 `DiffViewerProps` 和 `DiffViewerLabels`。逐行比较使用 [jsdiff](https://github.com/kpdecker/jsdiff)。
