## 安装 [#installation]

```bash
bunx --bun shadcn@latest add @sui/tooltip
```

通过 shadcn CLI 安装组件源码。按照[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

## 使用方法 [#usage]

```tsx showLineNumbers
import {
  Tooltip,
  TooltipContent,
  TooltipTrigger,
} from "@workspace/ui/components/tooltip"
```

```tsx showLineNumbers
<Tooltip>
  <TooltipTrigger>Hover</TooltipTrigger>
  <TooltipContent>
    <p>Add to library</p>
  </TooltipContent>
</Tooltip>
```

## 组合结构 [#composition]

使用以下组合来构建 `Tooltip`：

```text
Tooltip
├── TooltipTrigger
└── TooltipContent
```
