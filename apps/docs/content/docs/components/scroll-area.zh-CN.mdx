## 安装 [#installation]

```bash
bunx --bun shadcn@latest add @sui/scroll-area
```

通过 shadcn CLI 安装组件源码。按照[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

## 使用方法 [#usage]

```tsx showLineNumbers
import { ScrollArea, ScrollBar } from "@workspace/ui/components/scroll-area"
```

```tsx showLineNumbers
<ScrollArea className="h-[200px] w-[350px] rounded-md border p-4">
  Your scrollable content here.
</ScrollArea>
```

## 组合结构 [#composition]

使用以下组合来构建 `ScrollArea`：

```text
ScrollArea
└── ScrollBar
```

## 水平布局 [#horizontal]

使用 `ScrollBar` 和 `orientation="horizontal"` 进行水平滚动。
