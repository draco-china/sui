## 关于 [#about]

`Resizable` 组件是由 [bvaughn](https://github.com/bvaughn) 构建在 [react-ressized-panels](https://github.com/bvaughn/react-resizable-panels)] 之上。

## 安装 [#installation]

```bash
bunx --bun shadcn@latest add @sui/resizable
```

通过 shadcn CLI 安装组件源码。按照[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

## 使用方法 [#usage]

```tsx showLineNumbers
import {
  ResizableHandle,
  ResizablePanel,
  ResizablePanelGroup,
} from "@workspace/ui/components/resizable"
```

```tsx showLineNumbers
<ResizablePanelGroup orientation="horizontal">
  <ResizablePanel>One</ResizablePanel>
  <ResizableHandle />
  <ResizablePanel>Two</ResizablePanel>
</ResizablePanelGroup>
```

## 组合结构 [#composition]

使用以下组合来构建 `ResizablePanelGroup`：

```text
ResizablePanelGroup
├── ResizablePanel
├── ResizableHandle
└── ResizablePanel
```

## 更新记录 [#changelog]

### 2025-02-02 `react-resizable-panels` v4 [#2025-02-02-react-resizable-panels-v4]

已更新到 `react-resizable-panels` v4。完整变更见 [v4.0.0 发布说明](https://github.com/bvaughn/react-resizable-panels/releases/tag/4.0.0)。

直接使用 `react-resizable-panels` 底层组件时，请注意以下变更：

| v3                           | v4                      |
| ---------------------------- | ----------------------- |
| `PanelGroup`                 | `Group`                 |
| `PanelResizeHandle`          | `Separator`             |
| `direction` prop             | `orientation` prop      |
| `defaultSize={50}`           | `defaultSize="50%"`     |
| `onLayout`                   | `onLayoutChange`        |
| `ImperativePanelHandle`      | `PanelImperativeHandle` |
| `ref` prop on Panel          | `panelRef` prop         |
| `data-panel-group-direction` | `aria-orientation`      |

<Callout>
  shadcn/ui 的样式组件（`ResizablePanelGroup`、`ResizablePanel` 与 `ResizableHandle`）保持不变。
</Callout>
