`Item` 组件是一个简单的弹性容器，几乎可以容纳任何类型的内容。使用它来显示标题、描述和操作。将其与 `ItemGroup` 组件分组以创建项目列表。

## 安装 [#installation]

```bash
bunx --bun shadcn@latest add @sui/item
```

通过 shadcn CLI 安装组件源码。按照[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

## 使用方法 [#usage]

```tsx showLineNumbers
import {
  Item,
  ItemActions,
  ItemContent,
  ItemDescription,
  ItemMedia,
  ItemTitle,
} from "@workspace/ui/components/item"
```

```tsx showLineNumbers
<Item>
  <ItemMedia variant="icon">
    <Icon />
  </ItemMedia>
  <ItemContent>
    <ItemTitle>Title</ItemTitle>
    <ItemDescription>Description</ItemDescription>
  </ItemContent>
  <ItemActions>
    <Button>Action</Button>
  </ItemActions>
</Item>
```

## 组合结构 [#composition]

使用以下组合来构建 `Item`：

```text
ItemGroup
└── Item
    ├── ItemHeader
    ├── ItemMedia
    ├── ItemContent
    │   ├── ItemTitle
    │   └── ItemDescription
    ├── ItemActions
    └── ItemFooter
```

## Item 与 Field [#item-vs-field]

如果需要显示表单输入（例如复选框、输入、单选或选择），请使用 `Field`。

如果您只需要显示标题、描述和操作等内容，请使用`Item`。

## API 参考 [#api-reference]

### Item [#item]

显示带有媒体、标题、描述和操作的内容的主要组件

| 属性|类型 |默认 |
| --------- | ----------------------------------- | ----------- |
| `variant` | `"default" \| "outline" \| "muted"` | `"default"` |
| `size` | `"default" \| "sm" \| "xs"` | `"default"` |
| `render` | `React.ReactElement` |             |

### ItemGroup [#itemgroup]

将相关项目分组在一起并具有一致样式的容器。

```tsx
<ItemGroup>
  <Item />
  <Item />
</ItemGroup>
```

### ItemSeparator [#itemseparator]

组中项目之间的分隔符。

```tsx
<ItemGroup>
  <Item />
  <ItemSeparator />
  <Item />
</ItemGroup>
```

### ItemMedia [#itemmedia]

使用 `ItemMedia` 显示图标、图像或头像等媒体内容

| 属性|类型 |默认 |
| --------- | -------------------------------- | ----------- |
| `variant` | `"default" \| "icon" \| "image"` | `"default"` |

```tsx
<ItemMedia variant="icon">
  <Icon />
</ItemMedia>
```

```tsx
<ItemMedia variant="image">
  <img src="..." alt="..." />
</ItemMedia>
```

### ItemContent [#itemcontent]

包裹项目的标题和描述。

```tsx
<ItemContent>
  <ItemTitle>Title</ItemTitle>
  <ItemDescription>Description</ItemDescription>
</ItemContent>
```

### ItemTitle [#itemtitle]

显示项目的标题。

```tsx
<ItemTitle>Item Title</ItemTitle>
```

### ItemDescription [#itemdescription]

显示项目的描述。

```tsx
<ItemDescription>Item description</ItemDescription>
```

### ItemActions [#itemactions]

操作按钮或其他交互元素的容器。

```tsx
<ItemActions>
  <Button>Action</Button>
</ItemActions>
```

### ItemHeader [#itemheader]

在项目内容上方显示标题。

```tsx
<Item>
  <ItemHeader>Header</ItemHeader>
  <ItemContent>...</ItemContent>
</Item>
```

### ItemFooter [#itemfooter]

在项目内容下方显示页脚。

```tsx
<Item>
  <ItemContent>...</ItemContent>
  <ItemFooter>Footer</ItemFooter>
</Item>
```
