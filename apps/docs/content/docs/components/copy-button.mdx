## Installation

```bash
bunx --bun shadcn@latest add @sui/copy-button
```

Install with the shadcn CLI or use the shared `@workspace/ui` package. Follow the [installation guide](/docs/installation) to configure the registry, load styles, and choose import aliases.

```tsx
import { CopyButton } from "@workspace/ui/components/copy-button";
```

## Usage

```tsx
<CopyButton value={command} />
```

The icon morphs to a check mark after the clipboard write succeeds, or to a cross when it fails, and the tooltip and a polite live region say the same. The button is disabled while a write is pending. It is a [Tooltip Button](/docs/components/tooltip-button), so `variant`, `size`, `disabled` and `className` pass through; it defaults to a small ghost icon button. [Code Viewer](/docs/viewers/code-viewer), [Diff Viewer](/docs/viewers/diff-viewer) and the [Code Editor](/docs/components/code-editor) `copy()` plugin use it.

## Labels

`labels` overrides `copy`, `copied` and `copyFailed`. Pass `copyButtonLabelsZhCN` for Chinese.

## API reference

| Prop | Type | Default / behavior |
| --- | --- | --- |
| `value` | `string` | Required text to copy. |
| `labels` | `Partial<CopyButtonLabels>` | English labels. |
| `variant`, `size` | Button props | `"ghost"`, `"icon-sm"`. |
| `feedback` | `FeedbackOption` | Follows `FeedbackProvider`; haptics when a copy succeeds or fails. |

The module exports `CopyButtonProps`, `CopyButtonLabels`, `copyButtonLabels` and `copyButtonLabelsZhCN`.
