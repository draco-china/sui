## 安装 [#installation]

```bash
bunx --bun shadcn@latest add @sui/textarea
```

通过 shadcn CLI 安装组件源码。按照[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

## 使用方法 [#usage]

```tsx
import { Textarea } from "@workspace/ui/components/textarea"
```

```tsx
<Textarea />
```

## Field [#field]

使用 `Field`、`FieldLabel` 和 `FieldDescription` 创建带有标签和说明的文本区域。

<ComponentPreview name="textarea-field" previewClassName="*:max-w-xs" />

## 禁用状态 [#disabled]

使用 `disabled` 属性禁用文本区域。要设置禁用状态的样式，请将 `data-disabled` 属性添加到 `Field` 组件。

<ComponentPreview name="textarea-disabled" previewClassName="*:max-w-xs" />

## 无效状态 [#invalid]

使用 `aria-invalid` 属性将文本区域标记为无效。要设置无效状态的样式，请将 `data-invalid` 属性添加到 `Field` 组件。

<ComponentPreview name="textarea-invalid" previewClassName="*:max-w-xs" />
