## 安装 [#installation]

```bash
bunx --bun shadcn@latest add @sui/loader
```

通过 shadcn CLI 安装组件源码。按照[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

```tsx
import { Loader } from "@workspace/ui/components/loader";
```

## 使用 [#usage]

```tsx
<Loader variant="dots" label="正在加载消息" />
```

`Loader` 提供十八种不同的加载动效，使用当前文本颜色。根节点包含 `role="status"` 和加载文案，装饰图形对辅助技术隐藏。用户开启减少动态效果时，CSS 动画与字符帧定时器实时停止，保留静态指示；卸载时会清理定时器和媒体查询监听。服务器首屏使用静态字符帧，避免水合差异。

## 变体 [#variants]

| 变体 | 动效 |
| --- | --- |
| `spinner` | 圆形轨道上的旋转弧线 |
| `dash-ring` | 弧线沿旋转圆环平滑移动，随周期伸长与收缩 |
| `dots` | 三个点依次跳动 |
| `bars` | 四根条依次伸缩 |
| `dot-matrix` | 3 × 3 圆点波纹 |
| `dither` | 4 × 4 方块错序闪烁 |
| `ascii` | 字符旋转帧 |
| `ascii-line` | 线段字符旋转帧 |
| `ascii-braille` | 盲文环形旋转帧 |
| `ascii-blocks` | 块状字符高度变化 |
| `ascii-bounce` | 点状字符跳动帧 |
| `morph` | 圆形、方形、三角形、六边形连续变形并旋转 |
| `comet` | 带渐变尾迹的旋转彗星 |
| `scramble` | 字符重排逐步拼出 LOADING |
| `metaballs` | 两个黏连融合的圆球 |
| `newton` | 牛顿摆两端交替摆动 |
| `helix` | 双螺旋圆点往复运动 |
| `percent` | 装饰性的循环百分比与短条 |

`percent` 是循环加载图案，不代表已测量的任务进度。真实进度请使用 [Progress](/zh-CN/docs/components/progress)。

## 尺寸与配色 [#sizes-and-colors]

使用 `sm`（16px）、`default`（20px）、`lg`（28px），或数值指定像素尺寸。数值限制在 8–4096px，非有限数值回退到 20px。通过 `className="text-primary"` 使用当前主题色。

## 动画速度 [#animation-speed]

`speed` 设置基础周期，单位为秒，默认 `1`。数值越小越快；数值限制在 `0.1`–`86400`，非有限值回退到 `1`。字符帧定时器的最小间隔为 10 毫秒。复杂动效按基础周期的固定倍数播放。

```tsx
<Loader variant="dots" speed={0.6} label="正在加载" />
<Loader variant="metaballs" speed={2} label="正在加载" />
```

## API [#api]

| 属性 | 类型 | 默认值 |
| --- | --- | --- |
| `variant` | `LoaderVariant`，见上方十八种变体 | `"spinner"` |
| `size` | `"sm" \| "default" \| "lg" \| number` | `"default"` |
| `speed` | `number`，基础周期秒数 | `1` |
| `label` | `string` | `"Loading"` |
| `render` | React 元素或渲染函数 | `span` |

支持标准 `span` 属性、ref、style 和 `className`。根节点暴露 `data-slot="loader"` 与 `data-variant`。请使用准确描述实际操作的加载文案；百分比图案是装饰性循环，不暴露进度数值给辅助技术。组合与 ref 行为参见 [Base UI 文档](https://base-ui.com/react/handbook/composition)。
