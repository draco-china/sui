## 安装 [#installation]

```bash
bunx --bun shadcn@latest add @sui/aspect-ratio
```

通过 shadcn CLI 安装组件源码。按照[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

## 使用方法 [#usage]

```tsx showLineNumbers
import { AspectRatio } from "@workspace/ui/components/aspect-ratio"
```

```tsx showLineNumbers
<AspectRatio ratio={16 / 9}>
  <img src="..." alt="Image" className="rounded-md object-cover" />
</AspectRatio>
```

## 正方形 [#square]

使用 `ratio={1 / 1}` 属性的方形纵横比组件。这对于以方形格式显示图像很有用。
