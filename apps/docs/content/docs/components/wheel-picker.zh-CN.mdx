---
title: Wheel Picker
description: 支持甩动惯性、回弹落位、键盘选择与可选玻璃材质的圆柱滚轮。
---

WheelPicker 从有序列表中选择一个值。触摸、鼠标和手写笔直接拖动圆柱，越过两端时带橡皮筋阻尼；甩动后按惯性继续滑行，并以轻微回弹停在某一行。鼠标滚轮或触控板连续转动圆柱，停下后吸附到最近一行。中间一行是圆柱裁剪到选中带的清晰副本，文字在穿过选中带时恰好变清晰，且不会重复创建可访问列表。

## 安装 [#installation]

```npm
npx shadcn@latest add draco-china/sui/wheel-picker
```

按[安装指南](/zh-CN/docs/installation)加载 SUI 基础样式。默认包含明暗配色，其他预设按需加载。

## 用法 [#usage]

```tsx
import { WheelPicker } from "@workspace/ui/components/wheel-picker";

<WheelPicker
  aria-label="时长（分钟）"
  options={["15", "30", "45", "60"]}
  defaultValue="30"
  name="duration_minutes"
/>;
```

选项支持字符串或 `{ label, value }` 对象，值必须唯一。通过 `value` 和 `onValueChange` 控制选择；父组件拥有最终值，可以拒绝变更请求。非受控模式使用 `defaultValue`。未指定或找不到值时显示第一项。选项变化会约束显示位置，不会自动触发用户变更回调。

## 键盘与可访问性 [#accessibility]

滚轮是一个可聚焦的 listbox，使用 `aria-activedescendant` 和选中项状态。请提供本地化的 `aria-label` 或 `aria-labelledby`。上下方向键选择前后项，Home/End 到达两端，Page Up/Down 移动一个可视页；到达边界后不循环。

减少动态效果时保留同一列表和键盘操作，使用原地移动的平面列表，不旋转圆柱，也不播放落位动画。`disabled` 或空选项会移除 Tab 焦点并阻止变更。`name` 通过隐藏输入参与原生表单提交；表单重置会恢复非受控默认值。刻度音跟随 `feedback`，默认关闭；设置 `feedback="sound"` 或在 `FeedbackProvider` 中开启 sound 即可。与 beUI 参考一致，使用本地合成的 16ms 机械点击音：拖动、转动或惯性滑行中最近刻度变化时立即发声，停稳在同一刻度不会重复播放；键盘和直接选择也只播放一次。音频在用户手势开始时准备，多列共享一个音频上下文和缓冲区，快速移动时截断上一声尾音。初始渲染、表单重置和外部值更新保持静音，音频失败不会阻断选择。

## 材质 [#material]

默认是使用 SUI 语义色和 14px 文字的实色控件。`glass` 或 `frosted` 为边框区域应用共享材质，选项行保持普通，键盘焦点始终可见。圆柱自己接管手势，拖动或转动时不会带动后方页面滚动。

## API 参考 [#api-reference]

| 属性 | 类型 | 默认值 / 行为 |
| --- | --- | --- |
| `options` | `readonly WheelPickerOption[]` | 必填，值唯一。 |
| `value`、`defaultValue` | `string` | 受控值或非受控初始值。 |
| `onValueChange` | `(value: string) => void` | 用户选择时调用。 |
| `visibleCount` | `number` | `7`，规范为 3–11 的奇数。滚轮高度等于圆柱的投影高度；减少动态效果时每行占满一格。 |
| `itemHeight` | `number` | `36` 像素，最小 24。 |
| `disabled` | `boolean` | `false`。 |
| `feedback` | `FeedbackOption` | 跟随 `FeedbackProvider`；每滚过一行触发 selection 触感与刻度音。 |
| `name` | `string` | 可选表单字段名。 |
| `glass`、`frosted` | `boolean \| GlassConfig`、`boolean` | 默认普通材质。 |
| 其他属性 | 原生 div 属性 | 名称、`ref`、`className`、`style` 与事件回调。 |

导出 `WheelPicker`、`WheelPickerProps` 和 `WheelPickerOption`。交互参考 [beUI Wheel Picker](https://beui.dev/components/motion/wheel-picker)，SUI 实现使用 Motion 驱动圆柱。
