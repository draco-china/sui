## 安装 [#installation]

```bash
bunx --bun shadcn@latest add @sui/toggle-group
```

通过 shadcn CLI 安装组件源码。按照[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

## 使用方法 [#usage]

```tsx
import { ToggleGroup, ToggleGroupItem } from "@workspace/ui/components/toggle-group"
```

```tsx
<ToggleGroup type="single">
  <ToggleGroupItem value="a">A</ToggleGroupItem>
  <ToggleGroupItem value="b">B</ToggleGroupItem>
  <ToggleGroupItem value="c">C</ToggleGroupItem>
</ToggleGroup>
```

## 组合结构 [#composition]

使用以下组合来构建 `ToggleGroup`：

```text
ToggleGroup
├── ToggleGroupItem
└── ToggleGroupItem
```

## 更新记录 [#changelog]

### 2026-05-17 默认间距 [#2026-05-17-default-spacing]

默认 `spacing` 从 `0` 改为 `2`，让切换按钮组的各项默认保留间距。需要连成一组的样式时，使用 `spacing={0}`。
