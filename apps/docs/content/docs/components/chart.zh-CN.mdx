介绍**图表**。您可以将其复制并粘贴到应用程序中的图表组件的集合。

图表设计得看起来很棒，开箱即用。它们与其他组件配合良好，并且可以完全定制以适合您的项目。

[浏览图表库](https://ui.shadcn.com/charts)。

## 组件 [#component]

我们在后台使用 [Recharts](https://recharts.org/)。

我们设计 `chart` 组件时考虑到了组合。 **您可以使用 Recharts 组件构建图表，并且仅在需要的时间和地点引入自定义组件，例如 `ChartTooltip`**。

```tsx showLineNumbers /ChartContainer/ /ChartTooltipContent/
import { Bar, BarChart } from "recharts"

import { ChartContainer, ChartTooltipContent } from "@workspace/ui/components/chart"

export function MyChart() {
  return (
    <ChartContainer>
      <BarChart data={data}>
        <Bar dataKey="value" />
        <ChartTooltip content={<ChartTooltipContent />} />
      </BarChart>
    </ChartContainer>
  )
}
```

我们不包装 Recharts。这意味着您没有被锁定在抽象中。当Recharts新版本发布时，您可以按照官方升级路径升级您的图表。

**组件是你的**。

## 升级至 Recharts v3 [#updating-to-recharts-v3]

如果您要将旧的图表代码更新到 Recharts v3：

-  当您从 CSS 变量引用图表标记时，请使用 `var(--chart-1)` 而不是 `hsl(var(--chart-1))`。
-  仅将 `ChartTooltip.defaultIndex` 用于初始工具提示状态。将持久的活动形状保留在您自己的图表状态中。
-  当父 `<BarChart>` 已定义 `layout` 时，从 `<Bar>` 中删除 `layout`。
- 在 `ChartContainer` 上保留高度、`min-h-*` 或 `aspect-*`，以便 `ResponsiveContainer` 可以在首次渲染时进行测量。

## 图表配置 [#chart-config]

图表配置是您定义图表的标签、图标和颜色的地方。

它有意与图表数据分离。

这允许您在图表之间共享配置和颜色标记。对于数据或颜色令牌远程存在或以不同格式存在的情况，它还可以独立工作。

```tsx showLineNumbers /ChartConfig/
import { Monitor } from "lucide-react"

import { type ChartConfig } from "@workspace/ui/components/chart"

const chartConfig = {
  desktop: {
    label: "Desktop",
    icon: Monitor,
    // A color like 'hsl(220, 98%, 61%)' or 'var(--color-name)'
    color: "#2563eb",
    // OR a theme object with 'light' and 'dark' keys
    theme: {
      light: "#2563eb",
      dark: "#dc2626",
    },
  },
} satisfies ChartConfig
```

## 主题 [#theming]

图表具有对主题的内置支持。您可以使用 css 变量（推荐）或任何颜色格式的颜色值，例如 hex、hsl 或 oklch。

## 提示框组合 [#tooltip]

图表工具提示包含标签、名称、指示器和值。您可以使用这些的组合来自定义您的工具提示。

<ComponentPreview name="chart-tooltip" />

您可以使用 `hideLabel`、`hideIndicator` 属性打开/关闭其中任何一个，并使用 `indicator` 属性自定义指示器样式。

使用 `labelKey` 和 `nameKey` 为工具提示标签和名称使用自定义键。

图表附带 `<ChartTooltip>` 和 `<ChartTooltipContent>` 组件。您可以使用这两个组件将自定义工具提示添加到图表中。

```tsx title="components/example-chart.tsx"
import { ChartTooltip, ChartTooltipContent } from "@workspace/ui/components/chart"
```

```tsx title="components/example-chart.tsx"
<ChartTooltip content={<ChartTooltipContent />} />
```

### 属性 [#props]

使用以下属性来自定义工具提示

| 属性 |类型 |描述 |
| ：-------------- | :------------------------ | ：------------------------------------------------------ |
| `labelKey` |字符串|用于标签的配置或数据键 |
| `nameKey` |字符串|用于名称的配置或数据键  |
| `indicator` | `dot` `line` 或 `dashed` |工具提示的指示器样式         |
| `hideLabel` |布尔 |是否隐藏标签                   |
| `hideIndicator` |布尔 |是否隐藏指示器               |

### 颜色 [#colors]

颜色会自动从图表配置中引用。

### 自定义 [#custom]

要使用工具提示标签和名称的自定义键，请使用 `labelKey` 和 `nameKey` 属性。

```tsx showLineNumbers /browser/
const chartData = [
  { browser: "chrome", visitors: 187, fill: "var(--color-chrome)" },
  { browser: "safari", visitors: 200, fill: "var(--color-safari)" },
]

const chartConfig = {
  visitors: {
    label: "Total Visitors",
  },
  chrome: {
    label: "Chrome",
    color: "var(--chart-1)",
  },
  safari: {
    label: "Safari",
    color: "var(--chart-2)",
  },
} satisfies ChartConfig
```

```tsx title="components/example-chart.tsx"
<ChartTooltip
  content={<ChartTooltipContent labelKey="visitors" nameKey="browser" />}
/>
```

这将使用 `Total Visitors` 作为标签，使用 `Chrome` 和 `Safari` 作为工具提示名称。
