## 安装 [#installation]

```bash
bunx --bun shadcn@latest add @sui/kbd
```

通过 shadcn CLI 安装组件源码。按照[安装指南](/zh-CN/docs/installation)配置 registry、加载样式并选择导入别名。

## 使用方法 [#usage]

```tsx
import { Kbd } from "@workspace/ui/components/kbd"
```

```tsx
<Kbd>Ctrl</Kbd>
```

## 组合结构 [#composition]

使用以下组合来构建 `Kbd` 和 `KbdGroup`：

```text
Kbd
KbdGroup
├── Kbd
└── Kbd
```

## API 参考 [#api-reference]

### 快捷键组合 [#kbd]

使用 `Kbd` 组件显示键盘按键

| 属性 |类型 |默认 |
| ----------- | -------- | -------- |
| `className` | `string` | `` |

```tsx
<Kbd>Ctrl</Kbd>
```

### KbdGroup [#kbdgroup]

使用 `KbdGroup` 组件将 `Kbd` 组件组合在一起

| 属性 |类型 |默认 |
| ----------- | -------- | -------- |
| `className` | `string` | `` |

```tsx
<KbdGroup>
  <Kbd>Ctrl</Kbd>
  <Kbd>B</Kbd>
</KbdGroup>
```
