## 预览 [#preview]

在同一场景切换 CSS、SVG 折射和自动回退，对比普通与玻璃表面。演示显式使用 `mode="auto"`：清透按 WebGPU → SVG → CSS 回退，常规使用 SVG → CSS。可以切换站点明暗主题。

```bash
bunx --bun shadcn@latest add @sui/glass
```

## 使用 [#usage]

```tsx
import { GlassSurface } from "@workspace/ui/components/glass";

<GlassSurface className="rounded-2xl bg-background p-6">
  Glass surface
</GlassSurface>
```

通过组件的 `glassConfig` 单独选择材质和渲染方式；`glass` 仍只负责开关。局部配置保留 `strength`、`tint`、`tintOpacity` 和 `highlight` 四个参数，不开放模糊或最低文字对比度。局部配置不会写成 HTML 属性，显式 `glass={false}` 始终关闭效果。

```tsx
import { Button } from "@workspace/ui/components/button";
import { GlassSurface } from "@workspace/ui/components/glass";

<GlassSurface glassConfig={{ mode: "svg", material: "clear" }} />
<Button glass glassConfig={{ material: "regular" }}>操作</Button>
```

每个启用的表面使用独立请求，内部共享观察器、事件监听、渲染器与能力检测。复合组件的根可传递配置给操作控件和浮层；布局根自身不创建渲染请求，无需公开 Provider。

## 表面如何渲染 [#rendering]

首屏使用 CSS 模糊和圆角内侧柔光。测量后使用 SVG 边缘高光。原生 SVG 直接处理浏览器背后的实时画面，只有 WebGPU 使用解码后的采样帧替换背景。组件库默认 SVG → CSS，只有清透材质显式使用 `mode="auto"` 才请求 WebGPU；常规材质在自动模式下也使用 SVG → CSS。SVG 折射使用原生 `feDisplacementMap`；模糊与更清晰的折射边缘由 SVG 滤镜节点合成。两种渲染器保留随尺寸适配的平滑折射带。WebGPU 背景最高 2 倍采样，受 8 百万像素上限约束，坐标仍使用 CSS 像素。SVG 只生成几何位移图，不抓取背景。

Glass 保留布尔开关，通过 `glassConfig.material` 选择 `"clear"` 或 `"regular"` 材质。默认清透（Clear）的色调不透明度为 `10%`，常规（Regular）为 `35%`。使用 `<GlassSurface glassConfig={{ material: "regular" }} />` 选择常规材质。显式设置 `options.tintOpacity` 会覆盖材质默认值。Playground 的透明度在手动调节前跟随所选材质，恢复默认参数后回到当前材质的默认值。

骨架的 Glass 内部固定为 Regular＋CSS，不请求增强渲染器，外部仍只使用 `glass` 开关。其他需要折射的组件沿用局部或继承配置；组件只在确有固定材质需求时使用内部策略。

两种材质名称对应 [Apple 的 Clear 与 Regular 变体](https://developer.apple.com/design/human-interface-guidelines/materials)，这里的数值是 Web 近似参数，并非 Apple 官方规格。两种材质均保留折射强度 `22`、高光 `0.3`。模糊仍为内置值：WebGPU `2px`、SVG `4px`、CSS `6px`，不提供公开参数。

从底到顶依次合成背景折射、玻璃底色、组件填充色、边缘高光和内容。`tintOpacity` 控制玻璃底色，不会同时降低组件填充和高光的透明度。不透明主色保留实色，删除态保留自身填充的透明度；高光独立叠在填充之上。CSS、SVG 与 WebGPU 使用同一份材质合成结果。

完全不透底的填充使用 CSS 绘制并保留 SVG 高光，省去被填充覆盖的背景采样和折射计算。透光表面按所选模式增强；渲染状态会显示实际使用的模式。

## 输入、预览与浮层 [#composition]

通过 `glass` 为有材质表面的容器和操作控件启用效果。Card、Accordion 和 Toolbar 等容器使用一个连续表面，内部行、标签和分割线不单独绘制材质。玻璃容器内的控件默认复用所属表面，显式开启后可拥有独立材质；浮动菜单和 Tooltip 可拥有自己的表面。`glass={false}` 关闭当前组件及其继承设置，子组件可显式重新启用。Glass 视觉生效时不添加聚焦 ring，普通组件保留原有主题和焦点样式。

标签、面包屑、布局辅助、状态指示、表格和二维码保持普通样式。Markdown 和 HTML Viewer 的内容不使用 Glass；编辑器、代码与对比查看器、图片查看器、轮播和附件仅为操作控件提供 Glass，内容区保持普通样式，编辑器沿用既有 Monaco 生命周期。小型状态控件与骨架内部固定使用 Regular＋CSS。组件体验页同时展示普通组件和适合玻璃的表面，不为每个示例额外套一张玻璃卡片。

## WebGPU 采样与实时 SVG [#webgpu]

WebGPU 使用组件的 `glassConfig.captureTarget` 限定采样区域。相同目标、场景版本和遮挡集合共用快照；采样时排除自身、同绘制层级的 Glass 及上方遮挡，保留下层画面。层级结合所属玻璃表面和 CSS 堆叠上下文判断；真实 DOM 不被隐藏或移除。下层 Glass 更新后，使用它的上层请求重新采样。如果下层使用无法被 DOM 快照完整保留的原生背景滤镜，上层局部回退到 SVG，再回退到 CSS；其他请求仍可使用 WebGPU。

每个请求按自身光学范围过滤普通节点，并为折射和模糊预留边距。阴影、滤镜和可见伪元素可能越过元素矩形，因此保守保留。排除的图片在截图副本里先换成布局占位，再嵌入资源；排除的 canvas 在像素序列化前跳过，并在副本中补回等尺寸占位。实际保留的资源无法读取或嵌入时，该表面局部回退到 SVG，再回退到 CSS；独立请求仍可使用 WebGPU。不可读取资源使用现有快照条目记录失败，场景失效或刷新后重新尝试；临时采样失败则保留旧帧并允许重试。

自动模式在滚动或标记的运动期间优先使用可用的原生 SVG，停止后重新尝试 WebGPU。播放中的视频与其他保留的 DOM 绘制内容混合时也使用原生路径，暂停后尝试恢复 WebGPU；纯视频纹理仍可由 GPU 渲染，避免实时背景依赖反复过期的 DOM 截图。

DOM 采样最高 `5Hz`，原生 SVG 不可用时的运动采样最高 `10Hz`，不是 `60/120Hz` 实时渲染。`refreshGlass(target)` 为使用该目标的已挂载表面请求更新；不传目标时刷新所有已挂载请求。Playground 的两个视频背景保留；原生 SVG 与 CSS 由浏览器跟随视频和滚动画面，不使用 JS 背景快照，实际帧率仍需根据浏览器绘制与显示设备实测。

## 主题与回退 [#themes]

默认主题 token 不变，材质从组件自身背景读取颜色。最低文字对比度维持内置 `0`，不开放参数；组件自身文字色保持不变。无法完成增强时回退到 SVG 或 CSS。降低透明度偏好和强制颜色模式停用增强、显示不透明基础表面，并保留原生焦点样式。CSS 与 SVG 回退仍需检查实际背景上的文字可读性。

## 采样限制 [#limits]

这些限制针对 WebGPU 背景采样；原生 SVG 使用浏览器背后的画面，不进入 DOM 截图路径。DOM 快照不是浏览器合成器截图。跨域图像需要 CORS；iframe、复杂变换及浏览器管理的绘制内容可能无法准确采样。排除 canvas 时，如果无法可靠还原 Shadow DOM 插槽的布局，该表面局部使用原生 SVG，再回退到 CSS。过大的采样区域、快速动画和大量浮层会增加成本。WebGPU 保持原有快照结构，不包含额外的实时画布、嵌套合成层或全局主题备份。

## API 参考 [#api-reference]

| Prop | Type | 默认值 / 行为 |
| --- | --- | --- |
| Config `mode` | `"css" \| "svg" \| "auto"` | `"svg"`；SVG → CSS。Clear `auto`：WebGPU → SVG → CSS；Regular：SVG → CSS。 |
| Config `material` | `"clear" \| "regular"` | `"clear"`；色调不透明度 `10%` / `35%`。 |
| Config `options` | `GlassOptions` | 局部材质参数。 |
| Config `captureTarget` | `HTMLElement \| null \| RefObject<HTMLElement \| null>` | 可选 WebGPU 采样范围，SVG 与 CSS 不使用。 |
| `refreshGlass(target?)` | `(target?: GlassCaptureTarget) => void` | 刷新使用该目标的已挂载请求，不传目标时刷新全部。 |
| Options `strength` | `number` | `22` |
| Options `tint` | `string` | 组件自身背景。 |
| Options `tintOpacity` | `number` | 材质默认值 `0.1` / `0.35`；显式值优先。 |
| Options `highlight` | `number` | `0.3` |
| Surface `glass` | `boolean` | `true` |
| Component `glassConfig` | `GlassConfig` | 局部 `mode`、`material`、`options`、可选 WebGPU `captureTarget`；不包含开关或请求 ID。 |
| Surface other props | Native div props | `className`, `style`, `ref` |
