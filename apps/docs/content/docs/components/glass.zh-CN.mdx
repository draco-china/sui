
## 用法 [#usage]

```tsx
import { GlassSurface } from "@workspace/ui/components/glass";

<GlassSurface className="rounded-2xl bg-background p-6">
  Glass surface
</GlassSurface>
```

所有支持玻璃的组件都使用布尔开关 `glass`。`glassConfig` 选择材质 `material`、边缘光 `edge` 和三个参数 `options`：`strength`、`tint`、`tintOpacity`。模糊、饱和度和边缘高光强度均为内置。配置不会成为 HTML 属性，显式 `glass={false}` 始终关闭效果。

```tsx
import { Button } from "@workspace/ui/components/button";
import { GlassSurface } from "@workspace/ui/components/glass";

<GlassSurface glassConfig={{ material: "clear", edge: "vertical" }} />
<Button glass glassConfig={{ material: "regular" }}>Action</Button>
```

传入 `render` 可保留原生语义，例如 `<GlassSurface render={<nav />} />`。每个启用的表面都是独立请求；观察器、事件监听和 SVG 渲染器在内部共享，无需 Provider。Dialog、Popover、Tabs 等根组件把设置传给自己的控件和弹出层，本身不会成为玻璃。

## 渲染方式 [#rendering]

Glass 使用原生 SVG 折射：几何位移贴图通过 `feDisplacementMap` 在边缘弯折浏览器背后的实时画面，再进行模糊和饱和。不采集背景，因此视频、滚动和动画都按显示器帧率实时呈现。

CSS 材质作为回退：表面完成测量前、浏览器不支持 SVG 背景滤镜（Safari）、`prefers-reduced-transparency` 或强制颜色模式下，以及渲染器失败时使用。完全不透明的填充会遮住背景，因此这类表面保持 CSS 并保留共享的边缘高光。减少透明度和强制颜色模式下显示不透明底色，并保留原生焦点样式。

<ComponentPreview name="glass-dynamic" />

`refreshGlass(target?)` 重新测量元素或 ref 内已挂载表面的材质和边缘，不传目标时刷新全部。修改运行时无法观察到的填充后调用它。

## 材质 [#materials]

两种材质对应 [Apple 的 Clear 与 Regular 变体](https://developer.apple.com/design/human-interface-guidelines/materials)，数值是 Web 近似，不是 Apple 规范。

| 材质 | 着色 | SVG 模糊 | CSS 模糊 | 用途 |
| --- | --- | --- | --- | --- |
| `"clear"` 清透 | `12%` | `4px` | `6px` | 媒体之上的通透玻璃，背景仍可辨认。 |
| `"regular"` 常规（默认） | `30%` | `14px` | `16px` | 磨砂玻璃，在繁杂内容上保持文字清晰。 |

两者折射强度均为 `22`、饱和度 `1.3`，并使用相同的边缘光。`options.tintOpacity` 覆盖材质的着色。着色取自组件自身的背景，因此主色和危险色填充保留原有颜色。表面从底到顶依次合成折射后的背景、着色、组件填充、边缘高光和内容。

## 边缘光 [#edge]

`glassConfig.edge` 选择光线落在边缘的方式：

- `"diagonal"`（默认）：细边从左上和右下角照亮，沿两侧渐隐。
- `"vertical"`：斜面光照，反光位于上下边缘。

<ComponentPreview name="glass-edges" />

高光强度为内置，并随像素密度连续变化（`0.15 × 设备像素比`，范围 `0.15` 到 `0.3`），因此 1x 屏幕边缘更淡，手机上更细。

## 弹出层 [#popups]

开启玻璃时，菜单、弹出框、选择器、提示、悬停卡片、对话框、侧边面板、抽屉和通知默认使用清晰可读的常规材质和上下边缘光，与周围设置无关，与 Apple 平台一致。它们自身的 `glassConfig` 仍可另行选择。浮层共用一层柔和的扩散阴影。

## 控件与内容 [#composition]

玻璃用于导航、控件和浮层，内容保持普通。

- 玻璃表面内的控件共用该表面的材质，不会各自成为玻璃，除非显式开启。
- `ButtonGroup` 是一个胶囊，组内按钮共用其材质；嵌套分组时每个内层分组各自成为一个胶囊。`Pagination` 的控件也组成同样的胶囊。
- 表单字段（`Input`、`Textarea`、`InputGroup`、`Select` 与 `Combobox` 触发器、`TagInput`、`SensitiveInput`、`ClipboardText`）在玻璃范围内独立出现时成为玻璃，与 iOS 搜索框一致，获得焦点时轻微提亮。在对话框、面板等玻璃表面内，它们保持为普通字段并保留焦点环。
- Switch 和 Slider 的滑块只在拖动时成为玻璃镜片。按下按钮时会轻微放大，玻璃按钮同时提亮。
- 玻璃 `Carousel` 的上一张、下一张按钮浮于画面之上，幻灯片保持为内容。
- Card、二维码、Accordion、Calendar、编辑器和查看器属于内容：在玻璃中它们自身的控件保持普通，打开的菜单和弹出层仍使用玻璃。`Card` 和 `QRCode` 支持显式 `glass` 属性，例如用于媒体之上的小组件。
- 用 `GlassContent` 包裹自定义内容区域，可让其中的控件在玻璃表面内保持普通。

<ComponentPreview name="glass-controls" />

```tsx
import { Card } from "@workspace/ui/components/card";
import { GlassContent, GlassSurface } from "@workspace/ui/components/glass";

<GlassSurface>
  <GlassContent>{/* 普通表单字段 */}</GlassContent>
</GlassSurface>
<Card glass>{/* 玻璃小组件 */}</Card>
```

<ComponentPreview name="glass-composition" />

玻璃焦点不添加焦点环；普通组件保留主题和焦点样式。玻璃会透出背景，清透材质尤甚，因此两种材质中的文字和图标都带有与材质色调一致的柔和光晕，就像紧贴其后多了一层磨砂，次要文字也更接近前景色。光晕只在背景与文字冲突时显现，因此浅色和深色模式下都能在明亮繁杂的内容上保持清晰。普通按钮和输入框保持清晰的文字，减少透明度时，这些处理与玻璃一同关闭。

## API 参考 [#api-reference]

| 属性 | 类型 | 默认值 / 行为 |
| --- | --- | --- |
| Config `material` | `"clear" \| "regular"` | `"regular"`；弹出层默认 `"regular"`。 |
| Config `edge` | `"diagonal" \| "vertical"` | `"diagonal"`；弹出层默认 `"vertical"`。 |
| Config `options` | `GlassOptions` | 局部材质参数。 |
| Options `strength` | `number` | `22` |
| Options `tint` | `string` | 组件背景色。 |
| Options `tintOpacity` | `number` | 材质默认值：`0.12` / `0.3`。 |
| `refreshGlass(target?)` | `(target?: GlassTarget) => void` | 重新测量目标内的表面，不传目标时刷新全部。 |
| 组件 `glass` | `boolean` | 开启或关闭玻璃；`GlassSurface` 默认 `true`。 |
| 组件 `glassConfig` | `GlassConfig` | 局部 `material`、`edge` 和 `options`。 |
| `GlassSurface` | `useRender` 属性 | 原生 div 属性，可用 `render` 更换元素。 |
| `GlassContent` | `useRender` 属性 | 玻璃中的普通内容区域。 |
