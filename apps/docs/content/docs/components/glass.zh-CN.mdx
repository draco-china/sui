## 预览 [#preview]

在同一场景中比较普通表面与玻璃表面，并在清透玻璃与磨砂玻璃之间切换。状态行显示浏览器当前使用 SVG 折射还是 CSS 回退。切换站点外观可比较浅色与深色主题。

```bash
bunx --bun shadcn@latest add @sui/glass
```

## 用法 [#usage]

```tsx
import { GlassSurface } from "@workspace/ui/components/glass";

<GlassSurface className="rounded-2xl bg-background p-6">
  Glass surface
</GlassSurface>
```

所有支持玻璃的组件都有两个属性，且只描述组件自身：

| 属性 | 效果 |
| --- | --- |
| 不写 | 普通组件。 |
| `glass` | 使用默认值的清透液态玻璃。 |
| `glass={{ edge, strength, tint, tintOpacity, textGlow }}` | 使用这些设置的清透液态玻璃。 |
| `frosted` | 纯 CSS 绘制的磨砂玻璃。 |

没有任何继承：组件只有自己写了才是玻璃，与周围无关，设置也不会从父级传给子级。两者同时写时 `glass` 优先。`glass={false}` 等同于不写，因此可以直接写 `glass={enabled}`。

```tsx
import { Button } from "@workspace/ui/components/button";
import { GlassSurface } from "@workspace/ui/components/glass";

<GlassSurface glass={{ edge: "vertical" }} />
<GlassSurface frosted />
<Button glass>Action</Button>
```

传入 `render` 可保留原生语义，例如 `<GlassSurface render={<nav />} />`。`GlassSurface` 默认是清透玻璃，写了 `frosted` 时为磨砂。每个玻璃组件都是独立请求；观察器、监听器和 SVG 渲染器在内部共享，无需 Provider。

## 渲染 [#rendering]

清透玻璃使用原生 SVG 折射：几何位移贴图通过 `feDisplacementMap` 沿边缘弯折实时背景，再进行模糊和饱和处理。整个过程不截取画面，因此视频、滚动和动画都能以显示器帧率保持实时。

CSS 材质是它的回退：在表面完成测量前、浏览器无法绘制 SVG 背景时（Safari）、`prefers-reduced-transparency` 或强制颜色模式下，以及渲染器失败时生效。完全不透明的填充会遮住背景，这类表面保留 CSS 和共享的边缘高光。减少透明度与强制颜色模式显示不透明底色和原生焦点样式。

磨砂玻璃从不运行 JavaScript，也不加载渲染器：它只是作用在组件自身元素上的样式规则。

`refreshGlass(target?)` 重新测量元素或 ref 内已挂载的清透表面，不传目标时刷新全部。修改运行时无法观察到的填充后调用。

## 材质 [#materials]

两种材质参照 [Apple 的 Clear 与 Regular 变体](https://developer.apple.com/design/human-interface-guidelines/materials)；数值是 Web 上的近似实现，而非 Apple 规范。

| 属性 | 着色 | 模糊 | 折射与边缘光 | 用途 |
| --- | --- | --- | --- | --- |
| `glass` | `12%` | SVG `4px`，CSS 回退 `6px` | 有 | 媒体之上的通透玻璃，背景仍可辨认。 |
| `frosted` | `65%` | CSS `24px` | 无 | 磨砂玻璃，文字在繁杂内容上依然清晰。 |

清透玻璃折射强度为 `22`；两者饱和度均为 `1.3`。着色取自组件自身的背景，因此主色和危险色填充保留原有颜色。`glass={{ tintOpacity }}` 覆盖清透玻璃的着色。磨砂玻璃的着色取自组件的表面色；可在 CSS 中设置 `--frosted-base`、`--frosted-opacity` 或 `--frosted-blur` 调整。表面从底到顶依次合成模糊或折射后的背景、着色、组件填充、清透玻璃的边缘高光和内容。

## 边缘光 [#edge]

`glass={{ edge }}` 选择光线落在清透玻璃边缘的方式：

- `"diagonal"`（默认）：从左上角和右下角照亮的细边，沿两侧渐隐。
- `"vertical"`：上下边缘带反光的斜面。

<ComponentPreview name="glass-edges" />

高光强度为内置值，随像素密度连续变化（`0.15 × 设备像素比`，范围 `0.15` 到 `0.3`），因此 1x 屏幕上的边缘更淡。边缘线宽在所有屏幕上都是 0.9px。

边缘光属于清透玻璃，它会隐藏组件自身的边框、描边和焦点环。磨砂玻璃没有边缘光。与 iOS 一致，它靠材质反差和阴影勾勒轮廓，因此同样隐藏组件自身的边框和装饰描边；焦点环保留，开启增强对比度（`prefers-contrast: more`）时边框恢复。

## 弹出层 [#popups]

弹出层和其他组件一样自己选择材质：把 `glass` 或 `frosted` 写在内容组件上，例如 `PopoverContent`、`SelectContent` 或 `DialogContent`。`Popover`、`Select`、`Dialog` 等根组件没有玻璃属性。与 Apple 平台一致，繁杂内容上的菜单和对话框适合使用磨砂玻璃。浮层共用一层柔和的扩散阴影。

```tsx
<Select>
  <SelectTrigger glass />
  <SelectContent frosted>{/* 选项 */}</SelectContent>
</Select>
```

## 控件与内容 [#composition]

玻璃属于导航、控件和浮层；内容保持普通。

- 玻璃表面内的控件保持普通。在玻璃上优先使用 ghost 或 outline 变体，它们没有实色填充，直接落在材质上。
- 玻璃不会重复模糊：玻璃层里的玻璃或磨砂组件保留自己的着色和边缘光，但不再模糊或折射背景，因为嵌套的背景滤镜只会把外层内容再磨砂一次。弹出层不在触发器所在的层里，所以从玻璃工具栏打开的玻璃菜单仍是完整的独立一层。
- 玻璃 `ButtonGroup` 是一个胶囊，按钮落在它的材质上；组中组需要给每个内层组单独写 `glass`。`Toolbar`、`TabsList`、`PaginationContent` 和 `Command` 同理。
- 写了玻璃的表单字段（`Input`、`Textarea`、`InputGroup`、`SelectTrigger`、`ComboboxChips`、`TagInput`、`SensitiveInput`、`ClipboardText`）像 iOS 搜索框一样呈胶囊状，聚焦时略微提亮。
- 写了 `glass` 的 `Switch` 和 `Slider` 只在拖动时把滑块变成清透镜片。按下的按钮会轻微放大，玻璃按钮还会提亮。
- 自己渲染玻璃部件的组件会把属性传下去：`TabBar`（标签栏和镜片）、`NavigationMenu`（弹出层）、`Toaster`（通知）、`ImageViewer`（控件）、`ColorPicker`（触发器和弹出层）、`PaginationControls` 和 `PaginationPageSize`。
- Card、二维码、Accordion、Calendar、编辑器和查看器属于内容。`Card` 和 `QRCode` 接受 `glass` 或 `frosted`，例如用于媒体上的小组件。

```tsx
import { Card } from "@workspace/ui/components/card";
import { GlassSurface } from "@workspace/ui/components/glass";

<GlassSurface>{/* 普通内容与 ghost 控件 */}</GlassSurface>
<Card glass>{/* 玻璃小组件 */}</Card>
```

<ComponentPreview name="glass-composition" />

清透玻璃聚焦时不添加焦点环，磨砂玻璃保留组件自身的焦点环；普通组件保留主题和焦点样式。玻璃会透出背景，因此次要文字更接近前景色。在明亮繁杂的背景上，`glass={{ textGlow: true }}` 可为文字和图标加上与材质色调一致、紧贴字形的收敛光晕；默认关闭。光晕只在背景与文字冲突时显现，因此浅色和深色模式下都能保持清晰。磨砂玻璃更浓的着色无需光晕即可保持文字清晰。减少透明度时，光晕和次要文字处理与玻璃一同关闭。

## API 参考 [#api-reference]

| 属性 | 类型 | 默认值 / 行为 |
| --- | --- | --- |
| 组件 `glass` | `boolean \| GlassConfig` | 让该组件成为清透液态玻璃；`GlassSurface` 默认 `true`。 |
| 组件 `frosted` | `boolean` | 让该组件成为磨砂玻璃；与 `glass` 同时写时 `glass` 优先。 |
| Config `edge` | `"diagonal" \| "vertical"` | `"diagonal"`。 |
| Config `strength` | `number` | `22`。 |
| Config `tint` | `string` | 组件背景色。 |
| Config `tintOpacity` | `number` | `0.12`。 |
| Config `textGlow` | `boolean` | `false`。 |
| `refreshGlass(target?)` | `(target?: GlassTarget) => void` | 重新测量目标内的表面，不传目标时刷新全部。 |
| `GlassSurface` | `useRender` 属性 | 原生 div 属性，可用 `render` 更换元素。 |
