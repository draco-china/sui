---
title: Utilities
description: CSS effects for scroll containers and loading text, included in SUI’s shared styles.
---

SUI includes two CSS utilities from the shared shadcn styles. They use Tailwind CSS v4 classes and work with plain HTML or existing SUI components.

- [Scroll fade](/docs/utils/scroll-fade) masks overflowing content at the scrollable edges, with vertical, horizontal, and logical RTL variants.
- [Shimmer](/docs/utils/shimmer) adds a text highlight that follows the reading direction and respects reduced motion.

Both are loaded through `@workspace/ui/globals.css`. Each page includes runnable examples, copyable source, class references, accessibility guidance, and browser fallbacks.
