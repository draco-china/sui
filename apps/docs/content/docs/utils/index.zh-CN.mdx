---
title: 工具类
description: SUI 共享样式中的滚动边缘渐隐与文字微光效果
---

SUI 通过 shadcn 共享样式提供两套 CSS 工具类。它们使用 Tailwind CSS v4，可以直接用于 HTML 元素，也可与现有 SUI 组件组合。

- [Scroll fade](/zh-CN/docs/utils/scroll-fade)：让溢出内容在滚动边缘渐隐，支持纵向、横向以及 RTL 逻辑方向。
- [Shimmer](/zh-CN/docs/utils/shimmer)：为文字添加沿阅读方向移动的微光，并遵循减少动态效果设置。

导入 `@workspace/ui/globals.css` 即包含这两套工具类。每篇文档提供可运行的示例、可复制源码、类名参考、无障碍建议和浏览器降级说明。
