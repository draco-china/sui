## Installation [#installation]

```npm
npx shadcn@latest add @sui/bar-chart
```

Install with the shadcn CLI or use the shared `@workspace/ui` package. Follow the [installation guide](/docs/installation) to configure the registry, load styles, and choose import aliases.

## Usage [#usage]

```tsx
import { BarChart } from "@workspace/ui/charts/bar-chart";

<BarChart data={data} config={config} index="month" />;
```

## Horizontal and stacked [#horizontal]

`layout="horizontal"` puts categories on the y axis. Stacked bars round only the end of the stack.

## Customize [#customize]

The wrapper covers common cases. For more control, pass Recharts elements as `children`, or compose your own chart with the [Chart](/docs/charts/chart) primitives.

## API reference [#api-reference]

| Prop | Type | Default / behavior |
| --- | --- | --- |
| `layout` | `"vertical" \| "horizontal"` | `"vertical"`. |
| `stacked` | `boolean` | `false`. |
| `radius` | `number` | `8`. |
| `negativeColor` | `string` | `var(--destructive)`. |
| `index` | `string` | Required. The category-axis key. |
| `categories` | `readonly string[]` | Every key in `config`. |
| `showGrid` / `showXAxis` / `showYAxis` | `boolean` | Grid and x axis on; y axis varies by chart. |
| `dir` | `"ltr" \| "rtl"` | `"ltr"`. Mirrors the axes. |
| `data` | `readonly Record<string, unknown>[]` | Required rows. |
| `config` | `ChartConfig` | Required. Labels, colors and icons by key; series without a color use `--chart-1` to `--chart-5`. |
| `valueFormatter` | `(value: number) => string` | `toLocaleString`. Formats axes, tooltip and the screen-reader table; build one with `numberFormatter`. |
| `showLegend` | `boolean` | `false`. Legend buttons show and hide series. |
| `showTooltip` | `boolean` | `true`. |
| `loading` | `boolean` | `false`. Shows a skeleton. |
| `labels` | `Partial<ChartLabels>` | English labels; pass `chartLabelsZhCN` for Chinese. |
| `aria-label` | `string` | Names the figure and captions its data table. |
| `className` | `string` | Sizes the chart; defaults to a 16:9 box. |
| `children` | `ReactNode` | Extra Recharts elements, such as `ReferenceLine`. |

The module also exports `BarChartProps`, `numberFormatter`, and the label presets `chartLabels` and `chartLabelsZhCN`. Screen readers get a hidden data table while the drawing itself is hidden from assistive technology, and animation is off when reduced motion is requested.
