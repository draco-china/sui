---
title: 视觉基础
description: 色彩、字体、间距、布局、圆角、层级、图标、动效和深色模式，所有 SUI 组件共用的基础。
---

这些基础来自 `@workspace/ui/globals.css` 和组件本身。请使用这里列出的 token 和工具类，而不是写死的值，这样页面会跟随主题、深色模式和用户的偏好设置。每条规则的对照示例见[规范细则](/zh-CN/docs/design-guidelines)。

## 色彩 [#color]

按用途选颜色，不要按色相选。每个表面 token 都有配套的前景色：`bg-card` 配 `text-card-foreground`，`bg-primary` 配 `text-primary-foreground`。

| 用途 | Token | 场景 |
| --- | --- | --- |
| 画布与表面 | `background`、`card`、`popover`、`secondary`、`muted` | 页面、分组内容、浮层、次要控件、安静区域 |
| 主色 | `primary`、`primary-foreground` | 主操作，以及标签页、复选框等填充式选中 |
| 选中 | `accent`、`accent-foreground` | 悬停和选中项、当前链接 |
| 文字 | `foreground`、`muted-foreground` | 正文、说明和次要标签 |
| 线条与焦点 | `border`、`input`、`ring` | 分隔线、输入框底色、键盘焦点 |
| 危险 | `destructive`、`destructive-foreground` | 危险操作和无效输入 |
| 数据 | `chart-1` 到 `chart-5` | 只用于图表系列 |

- 只保留一个强调色。`pine`、`rose` 等配色会同时改变强调色、焦点和图表颜色，表面保持中性，详见[主题定制](/zh-CN/docs/theming)。
- 不要只靠颜色传达含义。状态要配文字或图标，图表系列要配图例或标注。
- SUI 没有成功、警告、信息这类 token。用文字和图标说明状态，或者在主题旁定义应用自己的 token。

## 字体 [#typography]

### 字体族 [#font-family]

SUI 使用各平台自带的界面字体，渲染清晰，也不需要下载字体文件：

```css
--font-sans: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue",
  Arial, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC",
  "Source Han Sans SC", sans-serif, "Apple Color Emoji", "Segoe UI Emoji",
  "Segoe UI Symbol", "Noto Color Emoji";
```

西文在 Apple 平台上用 SF，Windows 上用 Segoe UI，Android 上用 Roboto。中文依次回退到苹方、冬青黑体、微软雅黑，再到 Noto 或思源黑体；emoji 使用各系统的彩色字体。

- 组件里不要另设 `font-family`，统一读取 `--font-sans`（标题用的 `--font-heading` 也指向它）。
- 需要品牌字体时，在应用里覆盖 `--font-sans`，并把中文和 emoji 的回退字体保留在后面。

### 字号与行高 [#type-scale]

字号和行高使用 Tailwind 的阶梯。一个界面里控制在三到五种字号。

| 工具类 | 字号 / 行高 | 用途 | 字重 |
| --- | --- | --- | --- |
| `text-xs` | 12 / 16px | 说明、徽章、菜单中的标签 | `font-normal` 或 `font-medium` |
| `text-sm` | 14 / 20px | 正文、控件、表格单元格、数据 | `font-normal` |
| `text-base` | 16 / 24px | 长篇阅读，比如文章 | `font-normal` |
| `text-lg`、`text-xl` | 18 / 28px、20 / 28px | 分区标题 | `font-semibold` |
| `text-2xl`、`text-3xl` | 24 / 32px、30 / 36px | 页面标题 | `font-semibold` |

- 内容文字一律 14px：正文、按钮、输入框、表格单元格。16px 及以上用于标题和长篇阅读。
- 保留阶梯自带的行高，不要用 `leading-none`、`leading-tight` 压缩正文。

### 字重 [#font-weight-scale]

只用三种字重：400（`font-normal`）用于正文，500（`font-medium`）用于强调，600（`font-semibold`）用于标题。不要用 `font-bold`：中文笔画在 700 时会糊在一起，和 600 的差别也不值得这份杂乱。

### 中英混排 [#mixed-text]

- 中文与西文字母、数字之间留一个空格：「默认 `h-9`（36px）」「共 120 条」。
- 中文不加字间距，西文字间距保持字体本身的设置。
- 英文标题用句首大写；中文没有大小写，产品名等术语保持原样。
- 表格和统计数字用 `tabular-nums` 对齐；行内代码比周围文字小一级。

### 文字层级 [#text-levels]

只用两种文字颜色：需要阅读的文字用 `foreground`，说明、占位文字和次要标签用 `muted-foreground`。禁用的控件通过自身的 `disabled` 状态变淡；不要只靠浅色表达禁用、选中或无效。

## 间距 [#spacing]

间距采用 Tailwind 的 4px 步长。用得少、用得一致。

| 步长 | 数值 | 常见用途 |
| --- | --- | --- |
| `1`、`1.5`、`2` | 4–8px | 图标与标签、工具栏中的项、标签与输入框 |
| `3`、`4` | 12–16px | 表单中的字段、列表中的项、小号卡片的内边距（`size="sm"`） |
| `6` | 24px | 卡片内边距、页面中的分组 |
| `8`、`10`、`12` | 32–48px | 页面中的各个分区 |

- 相关的东西靠得更近：组内间距小于组与组之间的间距。
- 在 flex 和 grid 容器上用 `gap-*`，少给子元素加外边距。
- 文字周围的间距要按视觉调整，因为行框会在字形上下额外留出空间。

## 布局 [#layout]

应用页面用[布局组件](/zh-CN/docs/layouts/app-shell)搭建：`AppShell` 搭配侧边栏或顶部导航，`AppMain` 作为内容区，有自己分区的页面用 `SectionLayout`。

| 断点 | 宽度 | 变化 |
| --- | --- | --- |
| 手机 | 768px（`md`）以下 | 侧边栏变成抽屉，表格变成卡片，工具栏只保留搜索 |
| 平板 | 768–1023px | 侧边栏仍在内容旁边；分区标签为一行 |
| 桌面 | 1024px（`lg`）及以上 | 分区标签变成侧栏；工具栏完整显示 |

- 让内容区撑满可用空间并在内部滚动，标题、工具栏和分页始终可见（`AppMain fixed`、DataTable 的 `layout="fill"`）。
- 正文每行控制在约 70 个字符以内；表单很少需要超过 `max-w-2xl`。
- 使用逻辑属性（`ms-*`、`pe-*`、`start-*`），布局才能在从右到左的语言中正确镜像。

## 圆角 [#shape]

所有圆角都是 `--radius`（默认 `0.5rem`）的倍数，在根元素或容器上修改它，所有圆角会按比例缩放。

| 工具类 | 默认值 | 常见用途 |
| --- | --- | --- |
| `rounded-xl` | 12px | 表格、文字提示、嵌套的小表面 |
| `rounded-2xl` | 16px | 面板中的菜单项和选项 |
| `rounded-3xl` | 24px | 输入框、下拉选择、徽章、弹出框、菜单 |
| `rounded-4xl` | 32px | 按钮（在控件高度下呈胶囊形）、卡片、对话框 |
| `rounded-full` | — | 头像等圆形元素 |

控件共用同一套高度，放在一行时才能对齐：默认 `h-9`（36px），小号 `h-8`，大号 `h-10`。

一个圆角形状嵌在另一个里面、间距不超过 8px 时，保持同心：外圆角 = 内圆角 + 内边距。

## 层级 [#elevation]

层级用来区分图层，不用来表示重要性。层级越少越好。

| 层级 | 表面 | 用途 |
| --- | --- | --- |
| 基础 | `bg-background` | 页面 |
| 抬升 | `bg-card`，带 SUI Card 的阴影和描边 | 页面上的分组内容 |
| 浮层 | `bg-popover`，带阴影 | 菜单、弹出框、文字提示 |
| 覆盖 | Dialog、Sheet、Drawer，带遮罩 | 接管页面的任务 |

- 同一个表面不要同时用边框和投影；需要清晰边缘时用 `ring-1 ring-border`。
- 不要在抬升的卡片里再嵌套抬升的卡片。卡片内部用间距、分隔线或 muted 区域分组。
- 吸顶的标题栏或吸底的页脚，用边框和滚动内容分开，不用阴影。
- [玻璃](/zh-CN/docs/components/glass)是用在丰富背景上的浮动控件材质。在减少透明度、减少动态效果和强制颜色模式下，它会变回不透明的填充。

## 图标 [#icons]

图标来自 [Lucide](https://lucide.dev)，尺寸 16px（`size-4`）、线宽 2px，视觉上和 14px 文字一样大。

- 图标和所在文字的第一行居中对齐；文字会换行时，用 `h-lh flex items-center` 包住图标。
- 装饰性图标加 `aria-hidden`。只有图标的按钮需要无障碍名称，并用文字提示显示出来。
- 图标用来辅助标签，不取代标签，除非含义是通用的（关闭、搜索、更多）。

## 动效 [#motion]

动效用来解释变化。它要短，绝不阻塞输入，并遵循用户的偏好。

| 类型 | 时长 | 例子 |
| --- | --- | --- |
| 小型表面 | 100ms | 弹出框、菜单、对话框的淡入和缩放 |
| 遮罩 | 150ms | 侧边抽屉和对话框背后的暗色层 |
| 边缘表面 | 200ms | 从所在一侧滑入的侧边抽屉 |
| 拖动驱动的表面 | 跟随手势 | 滑动后归位的底部抽屉 |

- 悬停时颜色立即变化；只对位移和阴影做过渡。
- 浮层从它所属的位置进入：抽屉从所在的边，弹出框从触发它的元素。挂载时就打开的抽屉也会滑入。
- 收起时内容保持完整尺寸并被裁切，而不是被压扁。
- 在 `prefers-reduced-motion` 下，组件去掉位移，最多保留淡入淡出。

## 深色模式 [#dark-mode]

给根元素加上 `dark`。每个 token 都有深色值，组件不需要专门的深色类名。

- 用 token，深色模式就自然生效。写死的颜色（如 `bg-white`、`text-gray-500`）需要配一个 `dark:` 版本，这说明它应该换成 token。
- 在两种背景上都检查图片和插画；透明的图片如果看不清，给它一个底色。
- 默认跟随系统设置，并通过 [ThemeToggle](/zh-CN/docs/components/theme-toggle) 让用户在浅色、深色和跟随系统之间选择。选择的持久化由应用负责。
