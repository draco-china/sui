改编自 [shadcn-admin](https://github.com/satnaing/shadcn-admin) 的布局。`AppShell` 将 SUI Sidebar 组合为完整的后台框架：它提供布局偏好和跳转链接，内部组合 `AppSidebar` 和作为页面 main 地标的 `AppInset`。布局不依赖任何路由库，只需在 `AppShell` 上传入一次当前路径和路由 Link，内部所有导航都会读取它们。

## 侧栏框架

切换侧栏样式和折叠方式。`collapsible="icon"` 时收起侧栏，带子链接的分组会在侧栏旁弹出菜单。滚动内容区可以看到吸顶顶栏出现阴影。

## 安装 [#installation]

```bash
bunx --bun shadcn@latest add @sui/app-shell @sui/app-sidebar @sui/app-header @sui/app-main
```

需要横向导航时再添加 `@sui/top-nav`。注册表、依赖和样式配置见[安装指南](/zh-CN/docs/installation)。

## 用法 [#usage]

```tsx
import { Link, useLocation, useNavigate } from "@tanstack/react-router"
import { AppHeader } from "@workspace/ui/layouts/app-header"
import { AppMain } from "@workspace/ui/layouts/app-main"
import { AppInset, AppShell } from "@workspace/ui/layouts/app-shell"
import { AppSidebar } from "@workspace/ui/layouts/app-sidebar"
import type { LayoutLinkProps } from "@workspace/ui/layouts/types"

function RouterLink({ href, ...props }: LayoutLinkProps) {
  return <Link to={href} {...props} />
}

export function AuthenticatedLayout({ children }: { children: React.ReactNode }) {
  const pathname = useLocation({ select: (location) => location.pathname })
  const navigate = useNavigate()
  return (
    <AppShell
      currentPath={pathname}
      linkComponent={RouterLink}
      onNavigate={(href) => navigate({ to: href })}
    >
      <AppSidebar header={<TeamSwitcher />} navGroups={navGroups} footer={<NavUser />} />
      <AppInset>
        <AppHeader fixed breadcrumb={<PageBreadcrumb />}>
          <Search className="ms-auto" />
        </AppHeader>
        <AppMain>{children}</AppMain>
      </AppInset>
    </AppShell>
  )
}
```

`navGroups` 是 `{ title?, items }` 列表。每项可以是链接 `{ title, href, icon?, badge?, disabled? }`，也可以是分组 `{ title, icon?, items: 链接 }`。分组内有激活链接时默认展开。

偏好持久化由应用负责：从 cookie 或存储读取后传入 `defaultVariant`、`defaultCollapsible`、`defaultOpen`，并在 `onVariantChange`、`onCollapsibleChange`、`onOpenChange` 中保存。服务端读取可以避免首屏布局闪烁。在内部任何位置都可以用 `useLayout()` 读取和修改偏好。

## API

### AppShell

支持所有 `SidebarProvider` 属性（`defaultOpen`、`open`、`onOpenChange`、`className`）和 `LayoutProvider` 属性。

| 属性 | 默认值 | 说明 |
| --- | --- | --- |
| `variant`、`defaultVariant`、`onVariantChange` | `"inset"` | 侧栏样式：`sidebar`、`floating` 或 `inset`。 |
| `collapsible`、`defaultCollapsible`、`onCollapsibleChange` | `"icon"` | 折叠方式：`offcanvas`、`icon` 或 `none`。 |
| `currentPath` | `""` | 用于判断激活链接的当前路径。 |
| `linkComponent` | `<a>` | 路由 Link，接收 `href`、`className`、`aria-current` 和 `onClick`。 |
| `onNavigate` | `location.assign` | 非链接控件的跳转方式。 |
| `matcher` | 精确匹配 | `(href, currentPath) => boolean`。默认在路径完全一致时高亮，忽略查询参数和哈希。 |
| `skipLabel` | `"Skip to main content"` | 跳转链接文字。 |

### AppInset

侧栏旁的内容区，也是页面的 main 地标和跳转链接的目标。支持 `SidebarInset` 的所有属性。内部的 `AppMain fixed` 会让它固定为视口高度。

### AppSidebar

支持 `Sidebar` 属性，`variant` 和 `collapsible` 默认取 AppShell 偏好。

| 属性 | 默认值 | 说明 |
| --- | --- | --- |
| `header`、`footer` | — | 品牌或团队切换；用户菜单。 |
| `navGroups` | `[]` | 用 `NavGroup` 渲染的导航数据。 |
| `rail` | `true` | 切换侧栏的边缘轨道。 |

`NavGroup` 渲染单个分组，也可以在 `SidebarContent` 中单独使用。

### AppHeader

| 属性 | 默认值 | 说明 |
| --- | --- | --- |
| `fixed` | `false` | 吸附在滚动容器顶部，内容滚到下方时出现阴影和模糊。 |
| `sidebarTrigger` | `true` | 显示侧栏开关，需要在 AppShell 内。 |
| `breadcrumb` | — | 放在开关之后。 |

### AppMain

| 属性 | 默认值 | 说明 |
| --- | --- | --- |
| `fixed` | `false` | 占满剩余视口高度并在内部滚动，适合看板和表格。 |
| `fluid` | `false` | 占满宽度，不以 `max-w-7xl` 居中。 |

### TopNav

| 属性 | 默认值 | 说明 |
| --- | --- | --- |
| `links` | 必填 | 链接 `{ title, href, icon?, disabled? }`。 |
| `labels` | 英文 | `navigation`（地标名称）和 `menu`（菜单按钮）。 |
