---
title: Section Layout
description: Page heading with its own sub-navigation, such as settings or account pages.
---

Adapted from the shadcn-admin settings page. The sections are [Tabs](/docs/components/tabs) between the heading and the content, at every size; they scroll when they outgrow the page. Choosing one calls the layout's `onNavigate`, and the tabs take their accessible name from `title`.

<ComponentPreview name="layout-section" />

## Installation

```npm
npx shadcn@latest add @sui/section-layout
```

## Usage

```tsx
import { SectionLayout } from "@workspace/ui/layouts/section-layout"

<AppMain fixed>
  <SectionLayout title="Settings" description="Manage your account." items={items}>
    <Outlet />
  </SectionLayout>
</AppMain>
```

Inside an `AppShell`, links and active state come from its `currentPath` and `linkComponent`. Elsewhere, wrap the page in `LayoutProvider` with the same props.

## Vertical [#vertical]

`orientation="vertical"` stands the tabs in a side column from the `lg` breakpoint, on a rail between them and the content. The column is a fifth of the page wide but held between 192 and 256px; below `lg` the tabs are a scrolling row again. Use it for many sections, or for long section titles.

## API

| Prop | Default | Description |
| --- | --- | --- |
| `title` | Required | Page heading. |
| `description` | — | Text under the heading. |
| `items` | Required | Links `{ title, href, icon?, disabled? }`. |
| `orientation` | `"horizontal"` | `"vertical"` stands the tabs in a side column from `lg` up. |

`SectionTabs` renders the tabs alone, with `orientation` for a column. `SectionNav` renders the earlier link navigation: links from `lg` up, a scrolling row on tablets and a select on phones.
