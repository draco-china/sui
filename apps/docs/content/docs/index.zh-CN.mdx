SUI 是基于 Base UI 与 Tailwind CSS 4 构建的可组合 React 组件集合，为表单、导航、数据表格、布局、内容展示、聊天和图表提供一致的视觉基础，并可选触感与声音反馈。源码保存在 `packages/ui` 中，你可以直接阅读、修改，并按照应用需求自由组合。

## 从这里开始 [#start-here]

1. **安装组件。** 按照[安装指南](/zh-CN/docs/installation)，用 shadcn CLI 把组件添加到应用中。源码会放进你的项目，可直接修改。
2. **试用组件。** 浏览[组件目录](/zh-CN/docs/components)，每个页面都提供交互预览和完整示例源码。
3. **调整风格。** 通过[主题定制](/zh-CN/docs/theming)设置颜色与 CSS 变量，参考[规范细则](/zh-CN/docs/design-guidelines)统一字体、间距、表面和动效。

每个条目都通过 SUI 的 shadcn registry 以可编辑源码的形式安装，并带上所需的依赖和样式。

## 第一个组件 [#your-first-component]

安装组件后，通过应用自己的别名导入：

```npm
npx shadcn@latest add draco-china/sui/button
```

```tsx
import { Button } from "@/components/ui/button";

export function SaveButton() {
  return <Button>Save changes</Button>;
}
```

代码标签展示每个示例的完整文件，包含导入和组合方式，中英文页面共用这些示例。示例从 `@workspace/ui/components/*` 导入；在你的应用中请使用自己的别名，详见[导入安装后的源码](/zh-CN/docs/installation#import-installed-source)。

## 有目的地组合 [#compose-with-intent]

组件通过具名子组件表达结构。对话框由触发器、内容、标题、说明和操作组成；表单字段由标签、控件、说明和错误信息组成。将关联部分放在一起，保持交互完整，也让每一步操作都有清晰的目的。

Base UI 底层组件提供键盘交互、焦点管理和 ARIA 语义。应用仍需补充明确的标签、有用的说明和易于理解的反馈。请使用键盘与辅助技术验证自定义组合。

## 使用源码与文档 [#work-with-the-source]

- `packages/ui` 保存组件、共享 Hook、CSS 变量和强调色主题。
- `apps/docs` 保存双语文档站与可运行示例。
- [CSS 工具](/zh-CN/docs/utils)提供 Scroll Fade、Shimmer 等共享效果。

使用编程助手时，可通过 [llms.txt](/zh-CN/llms.txt)获取文档索引，通过 [llms-full.txt](/zh-CN/llms-full.txt)读取完整参考内容与示例源码。各文档页也可以通过页面操作查看 Markdown。
