# Glass / TabBar performance harness

Run from the repository root:

```sh
bunx vite --config apps/docs/tests/performance/vite.config.ts
```

Open `http://127.0.0.1:3011` in the browser used for comparison. Keep the
tab in the foreground, use the same window size and reduced-motion setting,
and press **Run benchmark**. Save the JSON output for both revisions and
repeat runs to distinguish regression from measurement noise.

Compare saved reports with:

```sh
bun apps/docs/tests/performance/compare.ts baseline.json optimized.json
```

For capture troubleshooting, open
`http://127.0.0.1:3011/?diagnostic=1&scenario=auto-drag`. This runs only the
eight-surface automatic mode, idle, drag and highlight cases, and logs scene
invalidations, snapshot keys, cache acceptance and capture failures. These
diagnostic timings include instrumentation and are not benchmark comparisons.

This standalone local harness uses the actual shared components, capture
implementation, vgpu renderer and WGSL. Capture instrumentation is applied
only by this Vite configuration; production source and APIs are unmodified.
It measures full capture duration, renderer queue/completion/readback/PNG
duration, native GPU image uploads, React Profiler commits, and supported
browser long tasks. Background upload and blur reuse are measured separately
from renderer initialization. CSS-only, single-surface, eight-surface, idle,
and long-press drag scenarios have separate counters.

Pointer moves are generated by fixture code after clicking the run button.
They measure component processing and rendering, not native input latency.
The harness runs development source with React profiling overhead, without
CPU throttling. Long tasks are only reported when the browser supports them.
CSS fallback is reported honestly when GPU creation or capture fails; such a
run cannot establish GPU performance or real WGSL refraction correctness.
Hardware, browser, DPR, reduced-motion mode, run label and time are included
in the report. A benchmark is evidence for optimization, not a universal
performance guarantee.
